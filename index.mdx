Final is a cloud platform for building with AI agents. Use one product or combine several: build your own agent, let the coding agent you already use work in a real cloud environment, or move your builds and deploys onto Final.

## Connect to Final

How you authenticate depends on the product.

| Product | How you connect |
| --- | --- |
| Agent SDK, Final VMs, Final Cloud Apps | An [API key](/api-keys) from the Final dashboard. |
| MCP gateway | [Sign in from your AI client](/mcp-gateway/quickstart). No API key needed. |
| Final CI Runners | [Enable your GitHub organization](/ci-runners/quickstart). Workflows don't need a key. |
