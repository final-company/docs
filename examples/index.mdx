Each example is a complete project: the agent's module and its files, the commands to publish or run it, and a script or request to try it, with the output you should see. They're ordered from simplest to most involved, so if you're new to the SDK, start at the top. Every example defines its agent the same way as the [quickstart](/quickstart): one `agent.ts` that lists every part and states what the agent requires, and a caller that provides it.

## Before you start

Every example needs Node.js 26 or later and a [Final API key](/api-keys) with the `agents:read`, `agents:write`, and `agents:execute` permissions. Export the key as `FINAL_API_KEY` and the ID of the project the examples run in as `FINAL_PROJECT_ID`. The scripts run with `npx tsx`, so install `@finalai/agents`, `zod`, and `tsx` in the example's project. Examples that call other services, like Linear, GitHub, or Stripe, say which token to store as a [secret](/operate/authentication#use-secrets-in-your-code) or which integration to create, and what access it needs.
