A linked repository collaborator mentions `@final` on a pull request. The GitHub channel posts their request as their own Final message, runs the agent in the pull request's connected Shared chat, and replies as the application on GitHub.

## Add the GitHub channel

For an agent with its own GitHub application:

```ts agent/channels/github.ts
import { githubChannel } from '@finalai/final-agent-provider/channels/github';
export default githubChannel();
```

For one installation shared across agents:

```bash
npx final-agents channel install @finalai/github-channel --project proj_your_project --install cinst_your_install
```

The command's package name is an alias for the factory above. Configure your own GitHub application, connector installation, and webhook subscription; official applications run the same code.

## Link and connect

Link your GitHub identity through user OAuth, then connect the pull request to a Shared chat. The channel verifies signatures and repository write access before accepting a mention. Unlinked collaborators receive one Link notice. Other senders do not start an agent turn.

Use Follow on the pull request when other chats should receive its status changes. A follow is an observe route: it delivers a resource event without connecting that chat as the pull request's conversation.

## Review the pull request

Give the agent a repository sandbox plus read-only tools for the diff and checks. Ask it to report failed validation, concrete bugs, and security problems with file references. Keep write actions behind approval in the shared chat.

Post a comment such as:

```text
@final review this change, including the authorization checks and test coverage.
```

The channel acknowledges the comment, then posts the completed answer as one GitHub comment. Replies are deduplicated by origin and turn. Long answers link back to Final. Permission requests name the requester in a Waiting notice; answer the decision in Final, where the platform verifies the respondent.

Editing or deleting the original comment updates the Final message by its external key. Edits to the agent's Final reply update the application's GitHub comment. GitHub exposes no reaction webhook, so reactions from Final can be sent to GitHub without treating GitHub reactions as inbound user events.
