This agent helps your support team with billing requests in Stripe. It looks up customers, applies account credits, and cancels subscriptions. Small credits and end-of-period cancellations go through on their own, while large credits and immediate cancellations wait for a person's OK. Use this pattern for any tool where most calls are routine and a few are risky, like refunds, deletes, or production changes.

**What it shows:** [serverless tools](/build/tools#in-process-or-serverless) that call a real API with a stored [secret](/operate/authentication#use-secrets-in-your-code), how to share helper code between serverless tools, and [`whenInput`](/build/tools#ask-before-a-tool-runs) approvals that look at each call's input.

### The agent

The three tools are serverless: their source travels inside the agent's document and runs on Final, so they work no matter which process starts the session. A serverless tool can't import modules or use variables from outside its own function, so each one reads the Stripe key and calls Stripe itself.

- `find_customer` only reads, so it never asks. It returns a compact summary instead of Stripe's full objects, which keeps the model's context small.
- `credit_account` asks for approval only when the credit is over $50. `whenInput` runs your function on each call's input before the tool runs, and asks a person only when it returns `true`.
- `cancel_subscription` lets a subscription run to the end of the period without asking, but asks before cutting it off now.

The two tools that change data send `ctx.callId` as Stripe's `Idempotency-Key`. It's unique to each tool call, so if a request is retried, Stripe applies it once.

```ts agent.ts expandable
import { defineAgent, defineServerlessTool, markdown } from '@finalai/agents';
import { whenInput } from '@finalai/agents/approval';
import * as z from 'zod';

// Serverless tools are self-contained: each one carries its own small Stripe helper.
const findCustomer = defineServerlessTool({
  description: 'Find a Stripe customer by email, with their balance and active subscriptions.',
  inputSchema: z.object({ email: z.email() }),
  annotations: { readOnlyHint: true },
  execute: async ({ email }, ctx) => {
    const key = await ctx.secrets.get('STRIPE_SECRET_KEY');
    if (key == null) throw new Error('The STRIPE_SECRET_KEY secret is not set');
    const stripe = async (path: string) => {
      const response = await fetch(`https://api.stripe.com/v1${path}`, {
        headers: { authorization: `Bearer ${key}` },
        signal: ctx.signal,
      });
      const data = await response.json();
      if (!response.ok) throw new Error(`Stripe: ${data.error?.message ?? response.status}`);
      return data;
    };

    const query = new URLSearchParams({ query: `email:'${email}'` });
    const customers: { data: { id: string; name: string | null; email: string | null; balance: number }[] } =
      await stripe(`/customers/search?${query}`);
    const customer = customers.data[0];
    if (customer == null) return { found: false };

    const subscriptions: {
      data: {
        id: string;
        cancel_at_period_end: boolean;
        items: { data: { price: { id: string; nickname: string | null } }[] };
      }[];
    } = await stripe(`/subscriptions?customer=${customer.id}&status=active`);
    return {
      found: true,
      id: customer.id,
      name: customer.name,
      email: customer.email,
      // Stripe stores credit as a negative balance.
      creditCents: Math.max(0, -customer.balance),
      subscriptions: subscriptions.data.map((s) => ({
        id: s.id,
        plan: s.items.data[0]?.price.nickname ?? s.items.data[0]?.price.id,
        cancelsAtPeriodEnd: s.cancel_at_period_end,
      })),
    };
  },
});

const creditAccount = defineServerlessTool({
  description: "Add a credit to a customer's Stripe balance. It applies to their next invoice.",
  inputSchema: z.object({
    customerId: z.string().startsWith('cus_'),
    amountCents: z.number().int().positive().max(50_000).describe('The credit, in cents'),
    reason: z.string().describe('Why the credit was given, shown on the customer record'),
  }),
  approval: whenInput<{ amountCents: number }>((input) => input.amountCents > 5_000),
  execute: async ({ customerId, amountCents, reason }, ctx) => {
    const key = await ctx.secrets.get('STRIPE_SECRET_KEY');
    if (key == null) throw new Error('The STRIPE_SECRET_KEY secret is not set');
    const response = await fetch(`https://api.stripe.com/v1/customers/${customerId}/balance_transactions`, {
      method: 'POST',
      headers: {
        authorization: `Bearer ${key}`,
        'content-type': 'application/x-www-form-urlencoded',
        // Unique to this tool call, so a retried request is applied once.
        'idempotency-key': ctx.callId,
      },
      body: new URLSearchParams({ amount: String(-amountCents), currency: 'usd', description: reason }),
      signal: ctx.signal,
    });
    const data = await response.json();
    if (!response.ok) throw new Error(`Stripe: ${data.error?.message ?? response.status}`);
    return { transactionId: data.id, creditCents: -data.ending_balance };
  },
});

const cancelSubscription = defineServerlessTool({
  description: 'Cancel a Stripe subscription, either at the end of the billing period or now.',
  inputSchema: z.object({
    subscriptionId: z.string().startsWith('sub_'),
    when: z.enum(['period_end', 'now']),
  }),
  approval: whenInput<{ when: 'period_end' | 'now' }>((input) => input.when === 'now'),
  execute: async ({ subscriptionId, when }, ctx) => {
    const key = await ctx.secrets.get('STRIPE_SECRET_KEY');
    if (key == null) throw new Error('The STRIPE_SECRET_KEY secret is not set');
    const response = await fetch(`https://api.stripe.com/v1/subscriptions/${subscriptionId}`, {
      method: when === 'now' ? 'DELETE' : 'POST',
      headers: {
        authorization: `Bearer ${key}`,
        'content-type': 'application/x-www-form-urlencoded',
        'idempotency-key': ctx.callId,
      },
      body: when === 'now' ? undefined : new URLSearchParams({ cancel_at_period_end: 'true' }),
      signal: ctx.signal,
    });
    const data = await response.json();
    if (!response.ok) throw new Error(`Stripe: ${data.error?.message ?? response.status}`);
    return { subscriptionId, canceled: when === 'now' ? 'now' : 'at period end' };
  },
});

export const agent = defineAgent({
  name: 'Billing Support',
  description: 'Looks up Stripe customers, issues credits, and cancels subscriptions.',
  instructions: markdown('./instructions.md', { from: import.meta.url }),
  secrets: ['STRIPE_SECRET_KEY'],
  tools: {
    find_customer: findCustomer,
    credit_account: creditAccount,
    cancel_subscription: cancelSubscription,
  },
  require: {
    harness: { permissionMode: 'ask' },
  },
});
```

The agent requires nothing but a harness: no compute and no integrations. `permissionMode: 'ask'` is a ceiling, so whoever starts it can't give it a harness that acts without asking. The `whenInput` predicates are serverless too, so they follow the same self-contained rule as the tools.

<Accordion title="Share helper code instead of repeating it">
  Repeating a ten-line helper in three tools is the simplest way to stay self-contained. When helpers grow, write the tools as ordinary modules that import whatever they need, bundle them into one ES module with a bundler such as esbuild, and pass that text as each tool's `source`, naming its export:

  ```ts
  import { readFileSync } from 'node:fs';
  import { defineServerlessTool } from '@finalai/agents';
  import * as z from 'zod';

  // One module, bundled with its helpers by your build (esbuild, Rollup) and imported as text.
  const tools = readFileSync(new URL('./dist/stripe-tools.js', import.meta.url), 'utf8');

  const findCustomer = defineServerlessTool({
    description: 'Find a Stripe customer by email, with their balance and active subscriptions.',
    inputSchema: z.object({ email: z.email() }),
    annotations: { readOnlyHint: true },
    source: tools,
    export: 'findCustomer',
  });
  ```

  The trade-off is a build step, and the whole bundle becomes part of the agent's document, so changing any helper changes the agent's hash. If a helper needs something only your app has, like a database connection, make the tool [in-process](/build/tools#in-process-or-serverless) instead.
</Accordion>

## Set it up

<Steps>
  <Step title="Create the project">
    Create the project the same way as in the [quickstart](/quickstart), then add the files above:

    ```bash
    mkdir billing-support && cd billing-support
    npm init -y && npm pkg set type=module
    npm install @finalai/agents zod
    npm install --save-dev typescript tsx @types/node
    ```

    `client.ts` creates the client and project from your environment, as in the quickstart:

    ```ts client.ts
    import { createClient } from '@finalai/agents/client';

    const apiKey = process.env.FINAL_API_KEY;
    const projectId = process.env.FINAL_PROJECT_ID;
    if (apiKey == null || projectId == null) throw new Error('Set FINAL_API_KEY and FINAL_PROJECT_ID');

    export const client = createClient({ auth: { apiKey } });
    export const project = client.project({ id: projectId });
    ```
  </Step>
  <Step title="Add a Stripe key">
    In Stripe, create a restricted key with write access to **Customers** and **Subscriptions** and nothing else. Start with a test-mode key while you try the agent. In the Final dashboard, add it under **Developer** > **Secrets** in the same project, with the name `STRIPE_SECRET_KEY`.
  </Step>
  <Step title="Check the document">
    Print the agent's document to confirm that each tool's source was captured:

    ```bash
    npx final-agents print ./agent.ts
    ```

    Each tool appears with `"placement": "serverless"` and its source. If a tool uses a name from outside its function, `print` fails and names it.
  </Step>
</Steps>

## Try it

This script plays the support agent: it starts a session, sends each line you type, streams the reply, and asks you in the terminal whenever a call needs approval. Change the email to a customer in your Stripe test data.

```ts support.ts
import { createInterface } from 'node:readline/promises';
import { sessionUpdateOf, textOf } from '@finalai/agents/client';
import { finalCredits, serverlessFinal } from '@finalai/agents/harnesses';
import { agent } from './agent.js';
import { client, project } from './client.js';

const terminal = createInterface({ input: process.stdin, output: process.stdout });

const { handle } = await project.sessions.create({
  agent,
  provide: {
    harness: serverlessFinal({
      model: 'deepseek-v4.1-flash',
      inference: finalCredits(),
    }),
  },
});

// Each line you type is a message. Approval requests interrupt the stream.
let message = await terminal.question('> ');
while (message.trim()) {
  const turn = await handle.send(message);
  const answered = new Set<string>();
  for await (const event of turn.stream()) {
    const update = sessionUpdateOf(event);
    if (update?.sessionUpdate === 'agent_message_chunk') process.stdout.write(textOf(update));

    if (event.decisionId != null && !answered.has(event.decisionId)) {
      answered.add(event.decisionId);
      const decision = (await handle.decisions()).find((d) => d.id === event.decisionId);
      if (decision == null) continue;
      const { title, body } = decision.request;
      const reply = await terminal.question(`\n\n${title}\n${body ?? ''}\nApprove? (y/n) `);
      await handle.respond({
        decisionId: decision.id,
        outcome: { action: reply.trim() === 'y' ? 'accept' : 'decline' },
      });
    }
  }
  message = await terminal.question('\n\n> ');
}

terminal.close();
await handle.close();
client.close();
```

```bash
npx tsx support.ts
```

Ask for a small credit, then a large one. Only the second one stops for approval. The exact wording varies:

```text
> jordan@example.com was double-charged for March. Credit them $20.

which applies to their next invoice. Their credit balance is now $20.00.

> Actually, the outage cost them a week. Make it another $120.
That's over $50, so I'm asking a manager to approve it.

Allow credit_account?
...
Approve? (y/n) y
Done. I added $120.00. Jordan's credit balance is now $140.00.
```

## Make it yours

- **Publish it for your team.** Run `npx final-agents publish ./agent.ts --name billing-support` so others can fetch it by name and add it to chats. Because every tool is serverless, a caller that only fetched the agent can still run it. See [publishing](/operate/publishing).
- **Route approvals to the right people.** In a real support tool, show the decision in your UI and let only managers answer it. The [support chat example](/examples/support-chat) shows how to forward decisions to a browser.
- **Keep an audit trail.** Add the [audit log hook](/examples/audit-log) so every credit and cancellation is recorded with who asked for it and who approved it.
