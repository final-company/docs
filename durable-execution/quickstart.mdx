---
title: "Durable Execution quickstart"
description: "Register a durable workflow and start runs with the public REST API."
---

Use the Durable Execution REST API to register workflows, emit events, start runs, and inspect results.

## Before you begin

You need an organization API key. Organization admins can create one in Final under **Settings** > **API Keys**.

Set the base URL and API key:

```bash
export FINAL_API_URL="https://api.final.ai"
export FINAL_API_KEY="<api-key>"
```

Durable Execution uses bearer authentication:

```bash
Authorization: Bearer <api-key>
```

For cross-product auth details, see [authentication](/authentication).

## Choose an app

The app ID is the durable namespace in the URL:

```bash
export FINAL_DURABLE_APP_ID="billing"
```

## Register a workflow

Register a workflow version with an HTTP worker runtime and an event trigger:

```bash
curl -X POST "${FINAL_API_URL}/v1/durable-execution/apps/${FINAL_DURABLE_APP_ID}/workflows" \
  -H "Authorization: Bearer ${FINAL_API_KEY}" \
  -H "Content-Type: application/json" \
  -d '{
    "workflowId": "send-receipt",
    "version": "1",
    "displayName": "Send receipt",
    "runtime": {
      "transport": "http",
      "url": "https://worker.example.com",
      "path": "/v1/execute"
    },
    "triggers": [
      {
        "kind": "event",
        "eventName": "invoice.paid",
        "expression": null
      }
    ]
  }'
```

See [register a workflow](/api-reference/durable-execution/workflows/register).

## Send an event

Send an event that matches the registered trigger:

```bash
curl -X POST "${FINAL_API_URL}/v1/durable-execution/apps/${FINAL_DURABLE_APP_ID}/events" \
  -H "Authorization: Bearer ${FINAL_API_KEY}" \
  -H "Content-Type: application/json" \
  -d '{
    "id": "evt_invoice_paid_123",
    "name": "invoice.paid",
    "data": {
      "invoiceId": "inv_123",
      "customerId": "cus_123"
    }
  }'
```

The response includes `scheduledRunIds` for new runs and `resumedRunIds` for waiting runs that the event resumed.

See [send events](/api-reference/durable-execution/events/send).

## Read a run

Fetch a run by ID:

```bash
curl "${FINAL_API_URL}/v1/durable-execution/apps/${FINAL_DURABLE_APP_ID}/runs/<run-id>" \
  -H "Authorization: Bearer ${FINAL_API_KEY}"
```

Read run history:

```bash
curl "${FINAL_API_URL}/v1/durable-execution/apps/${FINAL_DURABLE_APP_ID}/runs/<run-id>/history" \
  -H "Authorization: Bearer ${FINAL_API_KEY}"
```

See [get a run](/api-reference/durable-execution/runs/get) and [list run history](/api-reference/durable-execution/runs/history).
