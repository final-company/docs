---
title: "Tokens and SSH keys"
description: "Use Final API keys, VM tokens, and SSH public keys with Final Virtual Machines."
---

Virtual Machines use three credential types:

| Credential | Use it for |
| --- | --- |
| Final API key | Authenticating the CLI, SDK, and public REST API. |
| VM token | Granting scoped VM access where VM tokens are supported. |
| SSH public key | Connecting to VMs over SSH. |

## API keys

Create API keys in Final under **Settings** > **API Keys**. Use a user-owned API key for private VMs. Use `teamId` when you create a team-owned VM or when you use an ownerless organization API key.

Use the key as a bearer token:

```bash
curl "https://api.final.ai/v1/vms" \
  -H "Authorization: Bearer ${FINAL_VM_API_KEY}"
```

Use the same key with the CLI:

```bash
final-vm login --api-key "${FINAL_VM_API_KEY}"
```

For cross-product auth details, see [authentication](/developer-guides/authentication).

## VM tokens

Create VM tokens when you need a credential that can be revoked independently or scoped to a VM.

Use a Final API key to call the public API at `api.final.ai`. VM tokens are managed by the public API, but they do not authenticate public API requests.

```bash
final-vm token create ci-token --vm docs-demo --expires-days 30
```

The token value is returned once. Store it in your secret manager.

List and revoke tokens:

```bash
final-vm token ls
final-vm token revoke <token-id>
```

For API details, see [create a token](/api-references/virtual-machines/tokens/create), [list tokens](/api-references/virtual-machines/tokens/list), and [revoke a token](/api-references/virtual-machines/tokens/delete).

## SSH keys

Add your OpenSSH public key before using SSH:

```bash
final-vm ssh-key add laptop "$(cat ~/.ssh/id_ed25519.pub)"
```

List registered keys:

```bash
final-vm ssh-key ls
```

Remove a key by name:

```bash
final-vm ssh-key rm laptop
```

SSH key writes require a user context. Use a user-owned API key when you call the REST API directly.

See [list SSH keys](/api-references/virtual-machines/ssh-keys/list), [add an SSH key](/api-references/virtual-machines/ssh-keys/add), and [delete an SSH key](/api-references/virtual-machines/ssh-keys/delete).
