---
title: "Clone and work with a repository"
description: "Mint Git credentials, clone a Final Git repository, and push changes."
---

Use a repository ID to mint short-lived Git credentials. Then use the returned HTTPS remote with normal Git commands.

The repository Git credential endpoint returns both the remote URL and the Git `username` and `password`, which makes it convenient for clone workflows. If you already know the remote URL, you can also mint a `git` delegated credential with the [Delegated credentials API](/api-references/delegated-credentials/create).

## Full example

```bash
# Fill these in.
repository_id="<repository-id>"
FINAL_API_KEY="<api-key>"

# Mint credentials with write access.
credentials=$(curl -s -X POST "https://api.final.ai/v1/repositories/${repository_id}/git-credentials" \
  -H "Authorization: Bearer ${FINAL_API_KEY}" \
  -H "Content-Type: application/json" \
  -d '{"access":"write"}')

# Read the Git remote and HTTPS credentials from the response.
repo_path=$(echo "$credentials" | jq -r .repoPath)
remote_url=$(echo "$credentials" | jq -r .remoteUrl)
username=$(echo "$credentials" | jq -r .username)
password=$(echo "$credentials" | jq -r .password)
repo_dir=$(basename "$repo_path")

# Clone with the returned credentials.
git clone "https://${username}:${password}@${remote_url#https://}"
cd "$repo_dir"

# Commit and push.
git add .
git commit -m "Update repository content"
git push origin HEAD
```

Use `access: "read"` for clone and fetch. Use `access: "write"` for push.

Tokens expire quickly. Mint a new credential set for each workflow run. See the [mint Git credentials API reference](/api-references/repositories/mint-git-credentials) for request and response fields.

## Fetch later

```bash
repository_id="<repository-id>"
FINAL_API_KEY="<api-key>"

credentials=$(curl -s -X POST "https://api.final.ai/v1/repositories/${repository_id}/git-credentials" \
  -H "Authorization: Bearer ${FINAL_API_KEY}" \
  -H "Content-Type: application/json" \
  -d '{"access":"read"}')

remote_url=$(echo "$credentials" | jq -r .remoteUrl)
username=$(echo "$credentials" | jq -r .username)
password=$(echo "$credentials" | jq -r .password)

git fetch "https://${username}:${password}@${remote_url#https://}"
```
