---
title: "Manage repositories"
description: "Create Final Git repositories and mint short-lived Git credentials."
---

Use the console API to manage Git-backed file systems. Every request requires a production access token. For complete endpoint details, see the [API reference](/api-references).

```bash
access_token="<access-token>"
```

## Create a repository

```bash
curl -X POST "https://api.final.ai/api/file-systems" \
  -H "Authorization: Bearer ${access_token}" \
  -H "Content-Type: application/json" \
  -d '{
    "displayName": "Docs",
    "registrySlug": "docs",
    "defaultBranch": "main"
  }'
```

```json
{
  "fileSystem": {
    "id": "fs_123",
    "displayName": "Docs",
    "registrySlug": "docs"
  }
}
```

Use the returned `fileSystem.id` when minting Git credentials. See [create a repository](/api-references/repositories/create) for request and response fields.

## List repositories

See [list repositories](/api-references/repositories/list) for query parameters and response fields.

```bash
curl "https://api.final.ai/api/file-systems" \
  -H "Authorization: Bearer ${access_token}"
```

## Get a repository

See [get a repository](/api-references/repositories/get) for response fields.

```bash
file_system_id="<file-system-id>"

curl "https://api.final.ai/api/file-systems/${file_system_id}" \
  -H "Authorization: Bearer ${access_token}"
```

## Mint Git credentials

See [mint Git credentials](/api-references/repositories/mint-git-credentials) for request and response fields.

```bash
file_system_id="<file-system-id>"

curl -X POST "https://api.final.ai/api/file-systems/${file_system_id}/git-credentials" \
  -H "Authorization: Bearer ${access_token}" \
  -H "Content-Type: application/json" \
  -d '{"access":"write"}'
```

```json
{
  "repoId": "gsr_123",
  "repoPath": "org/repo",
  "remoteUrl": "https://git.us-west-2.portland.finalwebservices.com/git/org/repo.git",
  "defaultBranch": "main",
  "username": "final",
  "password": "<token>",
  "expiresAt": "2026-06-13T18:10:00.000Z"
}
```

The `username` and `password` fields are HTTPS Git credentials.

## Delete a repository

See [archive a repository](/api-references/repositories/archive) and [delete a repository](/api-references/repositories/delete) for response fields.

Archive marks the repository as archived:

```bash
file_system_id="<file-system-id>"

curl -X POST "https://api.final.ai/api/file-systems/${file_system_id}/archive" \
  -H "Authorization: Bearer ${access_token}"
```

Delete removes it:

```bash
file_system_id="<file-system-id>"

curl -X DELETE "https://api.final.ai/api/file-systems/${file_system_id}" \
  -H "Authorization: Bearer ${access_token}"
```

## Token scopes

| Access | Scopes |
| --- | --- |
| `read` | `repo:read`, `git:read` |
| `write` | `repo:read`, `repo:write`, `refs:write`, `git:read`, `git:write` |
