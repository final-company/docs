---
title: "Manage repositories"
description: "Create Final Git repositories and mint short-lived Git credentials."
---

Use the Final API to manage Git-backed repositories. Every request requires a user-owned API key. For complete endpoint details, see the [API reference](/api-references).

```bash
export FINAL_API_KEY="<api-key>"
```

## Create a repository

```bash
curl -X POST "https://api.final.ai/v1/repositories" \
  -H "Authorization: Bearer ${FINAL_API_KEY}" \
  -H "Content-Type: application/json" \
  -d '{
    "displayName": "Docs",
    "registrySlug": "docs",
    "defaultBranch": "main"
  }'
```

```json
{
  "repository": {
    "id": "gsr_123",
    "displayName": "Docs",
    "registrySlug": "docs"
  }
}
```

Use the returned `repository.id` when minting Git credentials. See [create a repository](/api-references/repositories/create) for request and response fields.

## List repositories

See [list repositories](/api-references/repositories/list) for query parameters and response fields.

```bash
curl "https://api.final.ai/v1/repositories" \
  -H "Authorization: Bearer ${FINAL_API_KEY}"
```

## Get a repository

See [get a repository](/api-references/repositories/get) for response fields.

```bash
repository_id="<repository-id>"

curl "https://api.final.ai/v1/repositories/${repository_id}" \
  -H "Authorization: Bearer ${FINAL_API_KEY}"
```

## Mint Git credentials

See [mint Git credentials](/api-references/repositories/mint-git-credentials) for request and response fields.

```bash
repository_id="<repository-id>"

curl -X POST "https://api.final.ai/v1/repositories/${repository_id}/git-credentials" \
  -H "Authorization: Bearer ${FINAL_API_KEY}" \
  -H "Content-Type: application/json" \
  -d '{"access":"write"}'
```

```json
{
  "repoId": "gsr_123",
  "repoPath": "org/repo",
  "remoteUrl": "https://git.us-west-2.portland.finalwebservices.com/git/org/repo.git",
  "defaultBranch": "main",
  "username": "final",
  "password": "<token>",
  "expiresAt": "2026-06-13T18:10:00.000Z"
}
```

The `username` and `password` fields are HTTPS Git credentials.

## Delete a repository

See [archive a repository](/api-references/repositories/archive) and [delete a repository](/api-references/repositories/delete) for response fields.

Archive marks the repository as archived:

```bash
repository_id="<repository-id>"

curl -X POST "https://api.final.ai/v1/repositories/${repository_id}/archive" \
  -H "Authorization: Bearer ${FINAL_API_KEY}"
```

Delete removes it:

```bash
repository_id="<repository-id>"

curl -X DELETE "https://api.final.ai/v1/repositories/${repository_id}" \
  -H "Authorization: Bearer ${FINAL_API_KEY}"
```

## API key permissions

| Permission | Enables |
| --- | --- |
| `repositories:read` | List repositories, read repository metadata, and mint read-only Git credentials. |
| `repositories:write` | Create, archive, and delete repositories, and mint read-write Git credentials. |

## Git credential access

| Access | Scopes |
| --- | --- |
| `read` | `repo:read`, `git:read` |
| `write` | `repo:read`, `repo:write`, `refs:write`, `git:read`, `git:write` |
