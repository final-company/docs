---
title: "Secrets"
description: "Store and manage user-owned secrets through the public API."
---

Use Secrets to store values that automation needs without putting plaintext credentials in code, logs, or configuration files.

Secrets are scoped to the API key owner inside the organization. Reads require `secrets:read`; creates, updates, value writes, and deletes require `secrets:write`.

The public API returns a UUID `id` for each secret. You can use that UUID or the secret `name` in `secretId` path parameters. Final-managed secret paths now use the Final namespace, such as `final/` in production.

For endpoint details, see the [Secrets API reference](/api-references/secrets/list).

## Create a secret

```bash
curl -X POST "https://api.final.ai/v1/secrets" \
  -H "Authorization: Bearer ${FINAL_API_KEY}" \
  -H "Content-Type: application/json" \
  -d '{
    "name": "github_token",
    "value": "ghp_example",
    "description": "GitHub token for deploy automation",
    "tags": {
      "service": "deploy"
    }
  }'
```

The response includes metadata, not the secret value:

```json
{
  "secret": {
    "id": "0193b000-0000-7000-8000-000000000101",
    "name": "github_token",
    "description": "GitHub token for deploy automation",
    "tags": {
      "service": "deploy"
    },
    "createdAt": "2026-06-16T00:00:00.000Z",
    "updatedAt": "2026-06-16T00:00:00.000Z"
  }
}
```

## Read metadata

List the secrets available to the API key owner:

```bash
curl "https://api.final.ai/v1/secrets" \
  -H "Authorization: Bearer ${FINAL_API_KEY}"
```

Read one secret by UUID or name:

```bash
curl "https://api.final.ai/v1/secrets/github_token" \
  -H "Authorization: Bearer ${FINAL_API_KEY}"
```

## Read or rotate a value

Read the current value:

```bash
curl "https://api.final.ai/v1/secrets/github_token/value" \
  -H "Authorization: Bearer ${FINAL_API_KEY}"
```

Write a new current value:

```bash
curl -X PUT "https://api.final.ai/v1/secrets/github_token/value" \
  -H "Authorization: Bearer ${FINAL_API_KEY}" \
  -H "Content-Type: application/json" \
  -d '{
    "value": "ghp_rotated"
  }'
```

## Update metadata

```bash
curl -X PATCH "https://api.final.ai/v1/secrets/github_token" \
  -H "Authorization: Bearer ${FINAL_API_KEY}" \
  -H "Content-Type: application/json" \
  -d '{
    "description": "Rotated GitHub token for deploy automation",
    "tags": {
      "service": "deploy",
      "rotation": "manual"
    }
  }'
```

## Delete a secret

```bash
curl -X DELETE "https://api.final.ai/v1/secrets/github_token" \
  -H "Authorization: Bearer ${FINAL_API_KEY}"
```
