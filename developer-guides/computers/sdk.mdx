---
title: "TypeScript SDK"
description: "Use the Final Computer TypeScript SDK to create computers and run commands from code."
---

Use `@final/computer-sdk` when your application needs to create computers, run commands, move files, or manage short-lived sandboxes from TypeScript.

## Authenticate

Create a client with a Final API key:

```ts
import { createComputerClient, orThrow } from "@final/computer-sdk";

const client = createComputerClient({
  baseUrl: "https://api.final.ai",
  auth: { apiKey: process.env.FINAL_COMPUTER_API_KEY! },
});
```

Every SDK call uses the same public REST API documented in the [Computers API reference](/api-references/computers).

## Create a computer

```ts
const computer = orThrow(
  await client.createComputer({
    image: "docker.io/library/node:22-slim",
    name: "sdk-preview",
    teamId: "team_1111117Hxt1fAWDjN7TY",
    httpPort: 3000,
    httpPublic: true,
    env: {
      NODE_ENV: "production",
    },
    idempotencyKey: "preview-123",
  }),
);

console.log(computer.getInfo().hostname);
```

Pass `teamId` as a `team_` ID to create a team-owned computer. Omit `teamId` to create a private computer for the acting user.

The SDK sends `idempotencyKey` as the `Idempotency-Key` header on the [create a computer endpoint](/api-references/computers/computers/create).

## Run commands

For buffered output, call `commands.run` without streaming callbacks:

```ts
const result = orThrow(
  await computer.commands.run("node --version", {
    timeoutMs: 30_000,
  }),
);

console.log(result.stdout);
```

For streamed output, pass `onStdout` or `onStderr`:

```ts
await computer.commands.run("npm test", {
  onStdout: (chunk) => process.stdout.write(chunk),
  onStderr: (chunk) => process.stderr.write(chunk),
  timeoutMs: 120_000,
});
```

Buffered execution uses [execute a command](/api-references/computers/execution/execute). Streaming execution uses the [exec WebSocket](/api-references/computers/execution/stream).

## Read and write files

```ts
orThrow(await computer.files.write("/srv/app/config.json", JSON.stringify({ mode: "preview" })));

const configText = orThrow(await computer.files.read("/srv/app/config.json"));
console.log(configText);
```

See [read a file](/api-references/computers/files/read) and [write a file](/api-references/computers/files/write) for request details.

## Use ephemeral computers

Use ephemeral computers for jobs that should clean themselves up:

```ts
const output = await client.withEphemeralComputer(
  { image: "docker.io/library/ubuntu:24.04" },
  async (sandbox) => {
    return orThrow(await sandbox.commands.run("uname -a")).stdout;
  },
);

console.log(output);
```

`withEphemeralComputer` creates the computer with `ephemeral: true` and deletes it after your callback finishes.

## Manage lifecycle

```ts
await computer.pause();
await computer.resume();
await computer.restart();

await computer.settings({
  vcpu: 4,
  memoryMb: 8192,
  diskGb: 40,
});

await computer.kill();
```

These helpers call the [perform a computer action](/api-references/computers/computers/action) and [update a computer](/api-references/computers/computers/update) endpoints.
