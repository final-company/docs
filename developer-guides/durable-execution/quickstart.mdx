Use the Durable Execution TypeScript SDK to define functions and connect workers. Use the public REST API or SDK helpers to send events, start runs, and inspect results.

## Before you begin

You need:

- A user-owned or team-owned API key for public REST API calls.
- A Durable Execution connect key for the namespace worker.
- Your Final organization ID, as an `org_` ID.
- Your Final user ID (`usr_`) or team ID (`team_`).

Organization admins can create API keys in Final under **Settings** > **API Keys**.

Set the base URL, API key, namespace, organization ID, owner user ID, and connect key:

```bash
export FINAL_API_URL="https://api.final.ai"
export FINAL_API_KEY="<api-key>"
export FINAL_DURABLE_NAMESPACE="billing"
export FINAL_ORGANIZATION_ID="org_1111117Hxt1fAWDjN7TW"
export FINAL_OWNER_USER_ID="usr_1111117Hxt1fAWDjN7TX"
export FINAL_DURABLE_CONNECT_KEY="<connect-key>"
```

For a team-owned durable namespace, use a team-owned API key and pass a `team_` ID as `teamId` to the SDK instead of `ownerUserId`.

Durable Execution uses bearer authentication:

```bash
Authorization: Bearer <api-key>
```

For cross-product auth details, see [authentication](/developer-guides/authentication).

## Install the SDK

Install the Durable Execution SDK:

```bash
npm install @finalai/durable-execution zod
```

## Define a namespace and function

Create a typed durable namespace and function:

```ts
import { createDurableExecution } from '@finalai/durable-execution';
import { z } from 'zod';

export const durable = createDurableExecution({
  namespace: process.env.FINAL_DURABLE_NAMESPACE!,
  organizationId: process.env.FINAL_ORGANIZATION_ID!,
  ownerUserId: process.env.FINAL_OWNER_USER_ID!,
  version: '2026-06-15',
  schemas: {
    'invoice.paid': z.object({
      invoiceId: z.string(),
      customerId: z.string(),
    }),
    'receipt.approved': z.object({
      invoiceId: z.string(),
      approvedBy: z.string(),
    }),
  },
  api: {
    baseUrl: process.env.FINAL_API_URL ?? 'https://api.final.ai',
  },
});

export const sendReceipt = durable.createFunction(
  {
    key: 'send-receipt',
    name: 'Send receipt',
    triggers: [durable.on('invoice.paid')],
    retries: 3,
  },
  async ({ event, step }) => {
    const invoice = await step.run('load-invoice', async () => {
      return {
        id: event.data.invoiceId,
        customerId: event.data.customerId,
      };
    });

    const approval = await step.waitForEvent('wait-for-approval', {
      event: 'receipt.approved',
      match: {
        invoiceId: invoice.id,
      },
      timeout: '24h',
    });

    return {
      invoiceId: invoice.id,
      approvedBy: approval.approvedBy,
    };
  },
);
```

## Connect a worker

Start a worker with `connect()`:

```ts
import { connect } from '@finalai/durable-execution';
import { durable, sendReceipt } from './durable';

const connection = await connect({
  client: durable,
  functions: [sendReceipt],
  apiUrl: process.env.FINAL_API_URL ?? 'https://api.final.ai',
  connectKey: process.env.FINAL_DURABLE_CONNECT_KEY!,
  instanceId: `worker-${crypto.randomUUID()}`,
  appVersion: '2026-06-15',
  maxWorkerConcurrency: 10,
});

await connection.closed;
```

`connect()` registers function manifests, creates a short-lived WebSocket session, opens the worker connection, refreshes tokens, and drains in-flight work during shutdown.

See [TypeScript SDK and workers](/developer-guides/durable-execution/typescript-sdk).

## Send an event

Send an event with the SDK:

```ts
await durable.send({
  id: 'evt_invoice_paid_123',
  name: 'invoice.paid',
  data: {
    invoiceId: 'inv_123',
    customerId: 'cus_123',
  },
});
```

Or send the same event through the public REST API:

```bash
curl -X POST "${FINAL_API_URL}/v1/durable-execution/namespaces/${FINAL_DURABLE_NAMESPACE}/events" \
  -H "Authorization: Bearer ${FINAL_API_KEY}" \
  -H "Content-Type: application/json" \
  -d '{
    "id": "evt_invoice_paid_123",
    "name": "invoice.paid",
    "data": {
      "invoiceId": "inv_123",
      "customerId": "cus_123"
    }
  }'
```

The response includes `scheduledRunIds` for new runs and `resumedRunIds` for waiting runs that the event resumed.

See [send events](/api-references/durable-execution/events/send).

## Trigger a function directly

Use direct triggers when you want to start one function without sending a normal event through the app trigger matcher:

```ts
const run = await durable.triggerFunction({
  functionKey: 'send-receipt',
  event: 'invoice.paid',
  data: {
    invoiceId: 'inv_123',
    customerId: 'cus_123',
  },
  idempotencyKey: 'inv_123',
});
```

See [trigger a workflow run](/api-references/durable-execution/runs/trigger).

## Read a run

Fetch a run by ID:

```bash
curl "${FINAL_API_URL}/v1/durable-execution/namespaces/${FINAL_DURABLE_NAMESPACE}/runs/<run-id>" \
  -H "Authorization: Bearer ${FINAL_API_KEY}"
```

Read run history:

```bash
curl "${FINAL_API_URL}/v1/durable-execution/namespaces/${FINAL_DURABLE_NAMESPACE}/runs/<run-id>/history" \
  -H "Authorization: Bearer ${FINAL_API_KEY}"
```

See [get a run](/api-references/durable-execution/runs/get) and [list run history](/api-references/durable-execution/runs/history).
