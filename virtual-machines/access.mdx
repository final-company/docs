---
title: "Tokens and SSH keys"
description: "Use organization API keys, VM tokens, and SSH public keys with Final Virtual Machines."
---

Virtual Machines use three credential types:

| Credential | Use it for |
| --- | --- |
| Organization API key | Authenticating the CLI, SDK, and public REST API. |
| VM token | Granting scoped VM access where VM tokens are supported. |
| SSH public key | Connecting to VMs over SSH. |

## Organization API keys

Organization admins can create API keys in Final under **Settings** > **API Keys**.

Use the key as a bearer token:

```bash
curl "https://api.final.ai/v1/vms" \
  -H "Authorization: Bearer ${FINAL_VM_API_KEY}"
```

Use the same key with the CLI:

```bash
final-vm login --api-key "${FINAL_VM_API_KEY}"
```

## VM tokens

Create VM tokens when you need a credential that can be revoked independently or scoped to a VM.

Use an organization API key to call the public API at `api.final.ai`. VM tokens are managed by the public API, but they do not authenticate public API requests.

```bash
final-vm token create ci-token --vm docs-demo --expires-days 30
```

The token value is returned once. Store it in your secret manager.

List and revoke tokens:

```bash
final-vm token ls
final-vm token revoke <token-id>
```

For API details, see [create a token](/api-reference/virtual-machines/tokens/create), [list tokens](/api-reference/virtual-machines/tokens/list), and [revoke a token](/api-reference/virtual-machines/tokens/delete).

## SSH keys

Add your OpenSSH public key before using SSH:

```bash
final-vm ssh-key add laptop "$(cat ~/.ssh/id_ed25519.pub)"
```

List registered keys:

```bash
final-vm ssh-key ls
```

Remove a key by name:

```bash
final-vm ssh-key rm laptop
```

SSH key writes require a user context. When you call the REST API directly, include a user-attributed request path that can provide that context.

See [list SSH keys](/api-reference/virtual-machines/ssh-keys/list), [add an SSH key](/api-reference/virtual-machines/ssh-keys/add), and [delete an SSH key](/api-reference/virtual-machines/ssh-keys/delete).
