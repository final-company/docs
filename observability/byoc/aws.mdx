---
title: "Deploy on AWS"
description: "Deploy an Observability data plane in your AWS account and register it with Final."
---

A BYOC data plane runs in an AWS account you own. BYOC is enabled per organization: ask Final to enable it, and Final provides the deployment and the data plane's release images.

## What runs in your account

| Component | Purpose |
| --- | --- |
| Container service | Runs the data plane from Final's published images. |
| Load balancer | The data plane's HTTPS endpoint, with your TLS certificate. |
| PostgreSQL | Ingest state, checkpoints, deletion records and scheduled work. |
| S3 bucket | Raw batches, attachments and large attribute values. |
| ClickHouse | Traces, spans, observations, scores and the SQL catalog. |

You provide:

- the VPC and subnets to deploy into;
- a TLS certificate for the endpoint's domain;
- a ClickHouse endpoint the data plane can reach, such as ClickHouse Cloud or your own cluster.

## Deploy and register

<Steps>
  <Step title="Deploy">
    Deploy the data plane into your account with the deployment Final provides, and review every change before you apply it. Keep the data plane's HTTPS endpoint and its PEM public key for the next step.
  </Step>
  <Step title="Register the data plane">
    An organization admin registers it for a project:

    ```ts
    await project.admin.registerDataPlane({
      endpoint: 'https://obs-dataplane.example.com',
      region: 'us-west-2',
      publicKey: dataPlanePublicKeyPem,
    });
    ```

    The endpoint must be HTTPS. A new registration starts as `pending`.
  </Step>
  <Step title="Check it">
    ```ts
    const plane = await project.admin.getDataPlane();
    console.log(plane.mode, plane.status, plane.lastSeenAt); // byoc active …
    ```

    Then run `npx final-obs doctor`: it sends a test span through Final's endpoint and reads it back from your data plane.
  </Step>
</Steps>

## Upgrades

Final publishes data plane images with each release. To upgrade, deploy the new version, reviewing the changes before you apply them.

## Rotate the key

Register the data plane again with its new public key. `register_data_plane` replaces the registration, including its key.
