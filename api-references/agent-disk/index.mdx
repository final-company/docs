---
title: "Agent Disk API"
description: "Reference for the Final Agent Disk REST API."
---

Use the Agent Disk API to create persistent disks for agents, manage disk-scoped users, create checkpoints and branches, share disk paths, and inspect usage.

Every request uses bearer authentication with a Final API key:

```bash
Authorization: Bearer <api-key>
```

The public Agent Disk API namespace is:

```text
https://api.final.ai/v1/agent-disk
```

Legacy Agent Disk token-management routes under `/tokens` are not exposed. Use standard Final API keys for public API requests.
