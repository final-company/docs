---
title: "Get a disk"
description: "Get one Agent Disk by ID."
api: "GET /v1/agent-disk/disks/{diskId}"
---

Returns one Agent Disk visible to the API key.

```bash
curl "https://api.final.ai/v1/agent-disk/disks/dsk_1111117Hxt1fAWDjN7Ta" \
  -H "Authorization: Bearer ${FINAL_API_KEY}"
```

## Path parameters

| Field | Type | Required | Description |
| --- | --- | --- | --- |
| `diskId` | string | Yes | Agent Disk wire ID with the `dsk_` prefix. |

## Response

Returns a JSON envelope whose `data` field is a disk object.
