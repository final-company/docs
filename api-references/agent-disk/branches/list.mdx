---
title: "List branches"
description: "List branches for an Agent Disk."
api: "GET /v1/agent-disk/disks/{diskId}/branches"
---

Lists branches for an Agent Disk.

```bash
curl "https://api.final.ai/v1/agent-disk/disks/dsk_1111117Hxt1fAWDjN7Ta/branches" \
  -H "Authorization: Bearer ${FINAL_API_KEY}"
```

## Path parameters

| Field | Type | Required | Description |
| --- | --- | --- | --- |
| `diskId` | string | Yes | Agent Disk wire ID with the `dsk_` prefix. |

## Response

Returns a JSON envelope whose `data` field is an array of branch objects.

```json
{
  "data": [
    {
      "id": "0193b000-0000-7000-8000-000000000301",
      "name": "experiment-a",
      "status": "available",
      "createdAt": "2026-06-17T21:11:30.000Z"
    }
  ]
}
```

Branches created from checkpoints can appear as `creating` until their replicas are open. Use a branch only after it is `available`.
