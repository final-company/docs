---
title: "Create a checkpoint"
description: "Create a checkpoint for an Agent Disk branch."
api: "POST /v1/agent-disk/disks/{diskId}/checkpoints"
---

Creates a checkpoint for a branch. If `branch` is omitted, the checkpoint is created from `main`.

```bash
curl -X POST "https://api.final.ai/v1/agent-disk/disks/dsk_1111117Hxt1fAWDjN7Ta/checkpoints" \
  -H "Authorization: Bearer ${FINAL_API_KEY}" \
  -H "Content-Type: application/json" \
  -d '{
    "name": "before-refactor",
    "branch": "main"
  }'
```

## Path parameters

| Field | Type | Required | Description |
| --- | --- | --- | --- |
| `diskId` | string | Yes | Agent Disk wire ID with the `dsk_` prefix. |

## Body

| Field | Type | Required | Description |
| --- | --- | --- | --- |
| `name` | string | Yes | Checkpoint name. |
| `branch` | string | No | Source branch. Defaults to `main`. |

## Response

Returns the created checkpoint in a JSON envelope.

```json
{
  "data": {
    "id": "0193b000-0000-7000-8000-000000000201",
    "name": "before-refactor",
    "branch": "main",
    "status": "sealed",
    "manifestKey": "manifests/main/11/manifest.json",
    "sealSeq": 11,
    "baseManifest": {
      "formatVersion": 1,
      "sealSeq": 11,
      "entries": [
        {
          "index": 11,
          "owner": "checkpoint",
          "source": "main",
          "durable": true,
          "entryBase64": "..."
        }
      ]
    },
    "createdAt": "2026-06-17T20:29:34.000Z"
  }
}
```

`manifestKey` identifies the checkpoint manifest stored by Agent Disk. `baseManifest` is the durable manifest used when creating a branch from the checkpoint.

Create branches only from sealed checkpoints. Branches created from checkpoints become usable after their status changes to `available`.
