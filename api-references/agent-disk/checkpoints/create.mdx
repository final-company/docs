---
title: "Create a checkpoint"
description: "Create a checkpoint for an Agent Disk branch."
api: "POST /v1/agent-disk/disks/{diskId}/checkpoints"
---

Creates a checkpoint for a branch. If `branch` is omitted, the checkpoint is created from `main`.

```bash
curl -X POST "https://api.final.ai/v1/agent-disk/disks/dsk_1111117Hxt1fAWDjN7Ta/checkpoints" \
  -H "Authorization: Bearer ${FINAL_API_KEY}" \
  -H "Content-Type: application/json" \
  -d '{
    "name": "before-refactor",
    "branch": "main"
  }'
```

## Path parameters

| Field | Type | Required | Description |
| --- | --- | --- | --- |
| `diskId` | string | Yes | Agent Disk wire ID with the `dsk_` prefix. |

## Body

| Field | Type | Required | Description |
| --- | --- | --- | --- |
| `name` | string | Yes | Checkpoint name. |
| `branch` | string | No | Source branch. Defaults to `main`. |

## Response

Returns the created checkpoint.
