---
title: "Offer work"
description: "Offer a work lease to WebSockets workers."
api: "POST /v1/websockets/work-queues/{queue}/offers"
---

Offers a work lease to workers connected to a WebSockets work queue.

Requires a user-owned or team-owned API key with `websockets:work`.

The queue is scoped to the API key owner. Offering work to `customer-jobs` with a user-owned key does not offer work to a team-owned `customer-jobs` queue.

The API also accepts `POST /v1/websockets/work-queues/offers` when you provide `queue` in the request body.

```bash
curl -X POST "https://api.final.ai/v1/websockets/work-queues/customer-jobs/offers" \
  -H "Authorization: Bearer ${FINAL_API_KEY}" \
  -H "Content-Type: application/json" \
  -d '{
    "leaseId": "lease_001",
    "payload": {
      "jobId": "job_001"
    }
  }'
```

## Path parameters

| Parameter | Type | Description |
| --- | --- | --- |
| `queue` | string | Owner-local work queue name. Do not prefix with `user:` or `team:`. |

## Request body

| Field | Type | Required | Description |
| --- | --- | --- | --- |
| `queue` | string | No | Queue name when using `/work-queues/offers`. |
| `leaseId` | string | Yes | Unique lease ID for this offered work item. |
| `payload` | any | Yes | JSON payload sent to workers. |

## Response

```json
{
  "offered": true,
  "jti": "issued-token-1"
}
```
