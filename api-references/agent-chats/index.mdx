---
title: "Agent Chats API"
description: "Reference for the public Agent Chats REST API."
---

Use the Agent Chats API to create agent chats, start sessions, send messages, poll state, and archive completed work.

Every request uses bearer authentication with an organization, team, or user API key:

```bash
Authorization: Bearer <api-key>
```

Organization-owned and team-owned keys must include `agentProfileId` when they create agent chats or sessions. Team-owned keys are scoped to agent profiles and agent chats for that team. User-owned keys act as the key owner.

Create requests must include `executionMode`. Use `cloud` for Final-managed cloud execution, or `local` when targeting local execution. Pass `finalNodeId` only when you want to run on a specific existing Final Node.

The public Agent Chats namespace is:

```text
https://api.final.ai/v1/agent-chats
```
