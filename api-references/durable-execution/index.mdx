---
title: "Durable Execution API"
description: "Reference for the public Durable Execution REST API."
---

Use the Durable Execution API to register workflows, send events, start runs, inspect history, cancel, retry, and signal waiting runs.

Every machine-facing request uses organization API key authentication:

```bash
Authorization: Bearer <api-key>
```

The public base URL is:

```text
https://api.final.ai/v1/durable-execution
```
