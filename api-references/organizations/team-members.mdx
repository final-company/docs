---
title: "Team members"
description: "List, add, update, and remove team members."
---

## List team members

`GET /v1/organizations/current/teams/{teamId}/members`

```bash
team_id="team_123"

curl "https://api.final.ai/v1/organizations/current/teams/${team_id}/members" \
  -H "Authorization: Bearer ${FINAL_API_KEY}"
```

Team member objects include a nested `user`, `role`, and `createdAt`.

## Add a team member

`POST /v1/organizations/current/teams/{teamId}/members`

Requires `organizations:write` and an organization-owned API key. The user must already belong to the organization.

```bash
team_id="team_123"
user_id="usr_123"

curl -X POST "https://api.final.ai/v1/organizations/current/teams/${team_id}/members" \
  -H "Authorization: Bearer ${FINAL_API_KEY}" \
  -H "Content-Type: application/json" \
  -d "{\"userId\":\"${user_id}\"}"
```

Returns `{ "added": true }`.

## Update a team member role

`PATCH /v1/organizations/current/teams/{teamId}/members/{userId}`

```bash
team_id="team_123"
user_id="usr_123"

curl -X PATCH "https://api.final.ai/v1/organizations/current/teams/${team_id}/members/${user_id}" \
  -H "Authorization: Bearer ${FINAL_API_KEY}" \
  -H "Content-Type: application/json" \
  -d '{
    "role": "maintainer"
  }'
```

Pass `null` for `role` to clear the team-specific role.

## Remove a team member

`DELETE /v1/organizations/current/teams/{teamId}/members/{userId}`

```bash
team_id="team_123"
user_id="usr_123"

curl -X DELETE "https://api.final.ai/v1/organizations/current/teams/${team_id}/members/${user_id}" \
  -H "Authorization: Bearer ${FINAL_API_KEY}"
```

Returns `{ "removed": true }`.
