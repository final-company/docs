---
title: "Teams"
description: "List, create, read, update, and delete teams."
---

## List teams

`GET /v1/organizations/current/teams`

```bash
curl "https://api.final.ai/v1/organizations/current/teams" \
  -H "Authorization: Bearer ${FINAL_API_KEY}"
```

Team objects include `id`, `organizationId`, `name`, `prefix`, `metadata`, `createdAt`, and `updatedAt`.

## Create a team

`POST /v1/organizations/current/teams`

Requires `organizations:write` and an organization-owned API key.

```bash
curl -X POST "https://api.final.ai/v1/organizations/current/teams" \
  -H "Authorization: Bearer ${FINAL_API_KEY}" \
  -H "Content-Type: application/json" \
  -d '{
    "name": "Support",
    "prefix": "SUP"
  }'
```

`prefix` must contain uppercase letters only and must be 2 to 5 characters long.

## Get a team

`GET /v1/organizations/current/teams/{teamId}`

```bash
team_id="team_123"

curl "https://api.final.ai/v1/organizations/current/teams/${team_id}" \
  -H "Authorization: Bearer ${FINAL_API_KEY}"
```

## Update a team

`PATCH /v1/organizations/current/teams/{teamId}`

Requires `organizations:write` and an organization-owned API key.

```bash
team_id="team_123"

curl -X PATCH "https://api.final.ai/v1/organizations/current/teams/${team_id}" \
  -H "Authorization: Bearer ${FINAL_API_KEY}" \
  -H "Content-Type: application/json" \
  -d '{
    "name": "Customer Support",
    "prefix": "CS"
  }'
```

Pass at least one of `name` or `prefix`.

## Delete a team

`DELETE /v1/organizations/current/teams/{teamId}`

Requires `organizations:write` and an organization-owned API key.

```bash
team_id="team_123"

curl -X DELETE "https://api.final.ai/v1/organizations/current/teams/${team_id}" \
  -H "Authorization: Bearer ${FINAL_API_KEY}"
```

Deleting a team also revokes team-scoped API keys for that team.
