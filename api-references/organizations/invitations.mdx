---
title: "Invitations"
description: "List, create, resend, and revoke organization invitations."
---

## List invitations

`GET /v1/organizations/current/invitations`

```bash
curl "https://api.final.ai/v1/organizations/current/invitations" \
  -H "Authorization: Bearer ${FINAL_API_KEY}"
```

Invitation objects include `id`, `email`, `state`, `acceptedAt`, `revokedAt`, `expiresAt`, `organizationId`, `inviterUserId`, `acceptedUserId`, `createdAt`, and `updatedAt`.

## Create an invitation

`POST /v1/organizations/current/invitations`

Requires `organizations:write` and an organization-owned API key.

```bash
curl -X POST "https://api.final.ai/v1/organizations/current/invitations" \
  -H "Authorization: Bearer ${FINAL_API_KEY}" \
  -H "Content-Type: application/json" \
  -d '{
    "email": "new.member@example.com",
    "roleSlug": "member",
    "expiresInDays": 30
  }'
```

| Field | Type | Required | Description |
| --- | --- | --- | --- |
| `email` | string | Yes | Invitee email address. |
| `roleSlug` | string | No | Organization role slug. Defaults to `member`. |
| `expiresInDays` | integer | No | Invitation lifetime from 1 to 90 days. Defaults to `30`. |

## Resend an invitation

`POST /v1/organizations/current/invitations/{invitationId}/resend`

```bash
invitation_id="invitation_123"

curl -X POST "https://api.final.ai/v1/organizations/current/invitations/${invitation_id}/resend" \
  -H "Authorization: Bearer ${FINAL_API_KEY}"
```

## Revoke an invitation

`DELETE /v1/organizations/current/invitations/{invitationId}`

```bash
invitation_id="invitation_123"

curl -X DELETE "https://api.final.ai/v1/organizations/current/invitations/${invitation_id}" \
  -H "Authorization: Bearer ${FINAL_API_KEY}"
```
