---
title: "Remove member"
description: "Remove a member from the organization."
api: "DELETE /v1/organizations/current/members/{membershipId}"
---

Requires `organizations:write` and an organization-owned API key.

Directory-managed memberships cannot be removed through this endpoint. Final also prevents removing the last active admin.

```bash
membership_id="om_123"

curl -X DELETE "https://api.final.ai/v1/organizations/current/members/${membership_id}" \
  -H "Authorization: Bearer ${FINAL_API_KEY}"
```

Returns `{ "deleted": true }`.
