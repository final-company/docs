---
title: "Organizations API"
description: "Reference for organization management endpoints."
---

Use the Organizations API to read and update the current organization, list roles, manage members, manage invitations, and manage teams.

Every request uses Final API key authentication:

```bash
Authorization: Bearer <api-key>
```

Reads require `organizations:read`. Mutations require `organizations:write` and an organization-owned API key.

The public base URL is:

```text
https://api.final.ai/v1/organizations
```
