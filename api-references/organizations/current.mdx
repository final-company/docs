title: "Current organization"
description: "Read and update the current organization."
---

## Get the current organization

`GET /v1/organizations/current`

Returns the organization associated with the API key.

```bash
curl "https://api.final.ai/v1/organizations/current" \
  -H "Authorization: Bearer ${FINAL_API_KEY}"
```

```json
{
  "organization": {
    "id": "org_123",
    "name": "Acme",
    "slug": "acme",
    "externalId": "acme-001",
    "metadata": {},
    "createdAt": "2026-06-17T12:00:00.000Z",
    "updatedAt": "2026-06-17T12:00:00.000Z"
  }
}
```

## Update organization metadata

`PATCH /v1/organizations/current`

Updates organization metadata. Requires `organizations:write` and an organization-owned API key.

```bash
curl -X PATCH "https://api.final.ai/v1/organizations/current" \
  -H "Authorization: Bearer ${FINAL_API_KEY}" \
  -H "Content-Type: application/json" \
  -d '{
    "metadata": {
      "costCenter": "platform"
    }
  }'
```

## List roles

`GET /v1/organizations/current/roles`

Returns available role definitions for the organization.

```bash
curl "https://api.final.ai/v1/organizations/current/roles" \
  -H "Authorization: Bearer ${FINAL_API_KEY}"
```

Role objects include `id`, `name`, `slug`, `description`, `permissions`, and `type`.
