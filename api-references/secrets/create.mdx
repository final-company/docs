---
title: "Create a secret"
description: "Create a secret for the API key owner."
api: "POST /v1/secrets"
---

Creates a secret and stores its first value.

Requires `secrets:write`.

```bash
curl -X POST "https://api.final.ai/v1/secrets" \
  -H "Authorization: Bearer ${FINAL_API_KEY}" \
  -H "Content-Type: application/json" \
  -d '{
    "name": "github_token",
    "value": "ghp_example",
    "description": "GitHub token for deploy automation",
    "tags": {
      "service": "deploy"
    }
  }'
```

## Body

| Field | Type | Required | Description |
| --- | --- | --- | --- |
| `name` | string | Yes | Secret name. Use letters, numbers, underscores, dashes, dots, plus, equals, or `@`. |
| `value` | string | Yes | Secret value to store. |
| `description` | string or null | No | Human-readable description. |
| `tags` | object | No | String key-value metadata. |

## Response

Returns `{ "secret": ... }` with secret metadata. The value is not returned.
