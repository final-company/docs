---
title: "List secrets"
description: "List secrets for the API key owner."
api: "GET /v1/secrets"
---

Lists secret metadata for the authenticated API key owner.

Requires `secrets:read`.

```bash
curl "https://api.final.ai/v1/secrets" \
  -H "Authorization: Bearer ${FINAL_API_KEY}"
```

## Response

```json
{
  "secrets": [
    {
      "id": "0193b000-0000-7000-8000-000000000101",
      "name": "github_token",
      "description": "GitHub token for deploy automation",
      "tags": {
        "service": "deploy"
      },
      "createdAt": "2026-06-16T00:00:00.000Z",
      "updatedAt": "2026-06-16T00:00:00.000Z"
    }
  ]
}
```
