---
title: "Read a secret value"
description: "Read the current value for a secret."
api: "GET /v1/secrets/{secretId}/value"
---

Reads the current secret value. `secretId` can be the full secret ID or the secret name.

Requires `secrets:read`.

```bash
curl "https://api.final.ai/v1/secrets/github_token/value" \
  -H "Authorization: Bearer ${FINAL_API_KEY}"
```

## Response

```json
{
  "secret": {
    "id": "sevenseas/prod/org_123/users/user_123/external-api/secrets/github_token",
    "name": "github_token",
    "description": "GitHub token for deploy automation",
    "tags": {
      "service": "deploy"
    },
    "createdAt": "2026-06-16T00:00:00.000Z",
    "updatedAt": "2026-06-16T00:00:00.000Z"
  },
  "value": "ghp_example"
}
```
