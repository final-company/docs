---
title: "Delete a secret"
description: "Delete a secret by UUID or name."
api: "DELETE /v1/secrets/{secretId}"
---

Deletes a secret. `secretId` can be the secret UUID or the secret name.

Requires `secrets:write`.

```bash
curl -X DELETE "https://api.final.ai/v1/secrets/github_token" \
  -H "Authorization: Bearer ${FINAL_API_KEY}"
```

## Response

```json
{
  "deleted": true
}
```
