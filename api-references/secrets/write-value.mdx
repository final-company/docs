---
title: "Write a secret value"
description: "Write a new current value for a secret."
api: "PUT /v1/secrets/{secretId}/value"
---

Writes a new current value for a secret. `secretId` can be the full secret ID or the secret name.

Requires `secrets:write`.

```bash
curl -X PUT "https://api.final.ai/v1/secrets/github_token/value" \
  -H "Authorization: Bearer ${FINAL_API_KEY}" \
  -H "Content-Type: application/json" \
  -d '{
    "value": "ghp_rotated"
  }'
```

## Body

| Field | Type | Required | Description |
| --- | --- | --- | --- |
| `value` | string | Yes | New secret value. |

## Response

Returns `{ "secret": ... }` with updated secret metadata.
