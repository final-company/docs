---
title: "Update a secret"
description: "Update secret metadata."
api: "PATCH /v1/secrets/{secretId}"
---

Updates metadata for a secret. `secretId` can be the full secret ID or the secret name.

Requires `secrets:write`.

```bash
curl -X PATCH "https://api.final.ai/v1/secrets/github_token" \
  -H "Authorization: Bearer ${FINAL_API_KEY}" \
  -H "Content-Type: application/json" \
  -d '{
    "description": "Rotated GitHub token for deploy automation",
    "tags": {
      "service": "deploy",
      "rotation": "manual"
    }
  }'
```

## Body

| Field | Type | Required | Description |
| --- | --- | --- | --- |
| `description` | string or null | No | Human-readable description. |
| `tags` | object | No | String key-value metadata. |

## Response

Returns `{ "secret": ... }` with updated secret metadata.
