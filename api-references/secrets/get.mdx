---
title: "Get a secret"
description: "Get secret metadata by ID or name."
api: "GET /v1/secrets/{secretId}"
---

Returns metadata for one secret. `secretId` can be the full secret ID or the secret name.

Requires `secrets:read`.

```bash
curl "https://api.final.ai/v1/secrets/github_token" \
  -H "Authorization: Bearer ${FINAL_API_KEY}"
```

## Path parameters

| Parameter | Type | Description |
| --- | --- | --- |
| `secretId` | string | Secret ID or name. |

## Response

Returns `{ "secret": ... }` with secret metadata.
