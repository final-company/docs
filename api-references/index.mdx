Use the API reference for endpoint details, request schemas, response schemas, and interactive examples.

Git endpoints use a production access token. Platform, Agent Workspaces, Virtual Machines, and Durable Execution endpoints use an API key. See [authentication](/developer-guides/authentication) for credential types and examples.

```bash
Authorization: Bearer <token>
Authorization: Bearer <api-key>
```
