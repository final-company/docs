---
title: "Get a delegated credential"
description: "Inspect lifecycle metadata for a delegated credential."
api: "GET /v1/delegated-credentials/{credentialId}"
---

Returns delegated credential metadata for the same owner. Secret material such as Git passwords and gateway tokens is not returned.

```bash
credential_id="dc_..."

curl "https://api.final.ai/v1/delegated-credentials/${credential_id}" \
  -H "Authorization: Bearer ${FINAL_API_KEY}"
```
