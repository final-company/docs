title: "Delegated credentials API"
description: "Reference for short-lived Final credentials."
---

Use delegated credentials to issue short-lived protocol credentials from a Final API key.

Every request uses Final API key authentication:

```bash
Authorization: Bearer <api-key>
```

The public base URL is:

```text
https://api.final.ai/v1/delegated-credentials
```

## Credential kinds

| Kind | Audience | Returned secret material |
| --- | --- | --- |
| `git` | `git` | `username`, `password` |
| `websockets` | `websockets` | `token`, `jti`, `url`, `protocolVersion` |
| `durable_worker` | `durable-execution` | `token`, `session` |

Short-lived credentials are not REST API bearer tokens. Use them only for the protocol they were minted for.
