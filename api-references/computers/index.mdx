---
title: "Computers API"
description: "Reference for the Final Computers REST API."
---

Use the public Computers REST API to create machines, run commands, read and write files, manage networking, and control access.

Every request to the public Computer API uses bearer authentication with a Final API key:

```bash
Authorization: Bearer <api-key>
```

Computers are scoped to one owner. Computer IDs use the `comp_` prefix. Private Computers return `ownerUserId` as a `usr_` ID; team-owned Computers return `teamId` as a `team_` ID. Pass a `team_` ID as `teamId` when creating a team-owned Computer or when using an ownerless organization API key.

The public Computer API namespace is:

```text
https://api.final.ai/v1/computers
```
