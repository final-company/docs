---
title: "Publish a channel event"
description: "Publish an event to a WebSocket Gateway channel."
api: "POST /v1/websocket-gateway/channels/{channel}/events"
---

Publishes an event to a gateway channel from the REST API.

Set `CHANNEL_NAME` to the channel your application uses. `chat` is only an example value, not a reserved Final channel.

The API also accepts `POST /v1/websocket-gateway/channels/events` when you provide `channel` in the request body.

```bash
CHANNEL_NAME="chat"

curl -X POST "https://api.final.ai/v1/websocket-gateway/channels/${CHANNEL_NAME}/events" \
  -H "Authorization: Bearer ${FINAL_API_KEY}" \
  -H "Content-Type: application/json" \
  -d '{
    "name": "message.created",
    "data": {
      "text": "hello"
    },
    "idempotencyKey": "message_001"
  }'
```

## Path parameters

| Parameter | Type | Description |
| --- | --- | --- |
| `channel` | string | Tenant-local channel name. Do not prefix with `org:`. |

## Request body

| Field | Type | Required | Description |
| --- | --- | --- | --- |
| `channel` | string | No | Channel name when using `/channels/events`. |
| `name` | string | No | Event name. Defaults to `message`. |
| `data` | any | Yes | JSON payload to deliver. |
| `idempotencyKey` | string | No | Idempotency key for the publish operation. |

## Response

```json
{
  "published": true,
  "jti": "issued-token-1"
}
```
