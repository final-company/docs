Use the WebSocket Gateway API to discover the hosted gateway URL, create short-lived session tokens, publish channel events, and offer work to connected workers.

Every request uses API key authentication:

```bash
Authorization: Bearer <api-key>
```

The public base URL is:

```text
https://api.final.ai/v1/websocket-gateway
```

## Permissions

| Permission | Required for |
| --- | --- |
| `websocket_gateway:connect` | `POST /sessions` |
| `websocket_gateway:publish` | Channel publish grants and `POST /channels/{channel}/events` |
| `websocket_gateway:history` | Channel history grants |
| `websocket_gateway:presence` | Channel presence grants |
| `websocket_gateway:rpc` | RPC grants |
| `websocket_gateway:bridge` | Bridge grants |
| `websocket_gateway:work` | Work queue grants and `POST /work-queues/{queue}/offers` |
