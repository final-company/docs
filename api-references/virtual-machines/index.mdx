---
title: "Virtual Machines API"
description: "Reference for the Final Virtual Machines REST API."
---

Use the public Virtual Machines REST API to create machines, run commands, read and write files, manage networking, and control access.

Every request to the public VM API uses bearer authentication with a Final API key:

```bash
Authorization: Bearer <api-key>
```

VMs are scoped to one owner. VM IDs use the `vm_` prefix. Private VMs return `ownerUserId` as a `usr_` ID; team-owned VMs return `teamId` as a `team_` ID. Pass a `team_` ID as `teamId` when creating a team-owned VM or when using an ownerless organization API key.

The public VM API namespace is:

```text
https://api.final.ai/v1/vms
```
