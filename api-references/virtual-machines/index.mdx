---
title: "Virtual Machines API"
description: "Reference for the Final Virtual Machines REST API."
---

Use the public Virtual Machines REST API to create machines, run commands, read and write files, manage networking, and control access.

Every request to the public VM API uses bearer authentication with an organization API key:

```bash
Authorization: Bearer <api-key>
```

The public VM API namespace is:

```text
https://api.final.ai/v1/vms
```
