---
title: "Online evaluation"
description: "Judge agent turns and workflow runs as they finish, with environments, conditions, sampling, session windows and backfills."
---

Online evaluation runs judges on your project's agent turns and workflow runs as they finish. When a turn ends or a run completes, Final matches every online judge against it, and each match becomes one evaluation at the judge's pinned evaluator version.

## Run settings

```ts
import { ConditionField, ConditionJoin, ConditionOperator } from '@finalai/agents/o11y';

await o11y.judges.setJudgeRunSettings({
  judgeId,
  runSettings: {
    online: true,
    environments: ['prod'],
    samplingPercent: 20,
    conditions: {
      join: ConditionJoin.And,
      conditions: [
        { field: ConditionField.SpanName, op: ConditionOperator.Eq, value: 'invoke_agent' },
        { field: ConditionField.DurationMs, op: ConditionOperator.Gt, value: 5_000 },
      ],
    },
  },
});
```

| Setting | What it does |
| --- | --- |
| `online` | Evaluate finished turns and runs. |
| `environments` | Required when `online` is true. Only traces from these environments are evaluated. Agents and workflows running on Final report `prod`. |
| `conditions` | Optional [condition groups](/o11y/judges#deterministic-judges) the trace's root span must match. |
| `samplingPercent` | 0 to 100. |
| `sessionTrigger` | For session judges: when to score a session. See [session windows](#session-windows). |

Run settings replace the previous ones. They don't change the judge's evaluator version: pin that on the judge.

## What conditions see

Online conditions are checked when the trace finishes, against its root span:

| Field | Value |
| --- | --- |
| `span_name` | `invoke_agent` for an agent turn, `workflow <name>` for a workflow run. |
| `duration_ms` | The turn's or run's duration. |
| `error` | Whether the turn or run failed. |
| `attribute` | `deployment.environment.name`, `gen_ai.conversation.id` (the session) and `final.agent.hash` (the agent version). |

To evaluate only some agent versions, match `final.agent.hash` with `in`. To evaluate one workflow, match its root span name.

## When a trace is evaluated

- **Agent turns** are evaluated when the turn ends. A judge never evaluates its own judging sessions.
- **Workflow runs** are evaluated when the run completes, fails or is cancelled. Dry runs aren't evaluated.

Each judge evaluates a trace at most once, so a redelivered or repeated signal never evaluates it twice. Evaluations from online runs are the only ones that publish `o11y.judge.matched`, which starts [actions](/o11y/actions).

## Sampling

Sampling is stable: whether a trace is sampled depends only on the judge and the trace, so retries agree, and raising the rate only adds traces (a trace sampled at 10% is also sampled at 20%). Each result records the rate in force, so rates computed from samples stay correct when you change it.

## Session windows

Session judges score windows of a session's turns. `sessionTrigger.kind` sets when a window is scored:

| Kind | Scores a window when |
| --- | --- |
| `inactivity` | The session has had no new turn for `inactivityMinutes` (1 to 10,080). |
| `new_traces` | New turns arrive. |
| `either` | Whichever happens first. |

```ts
import { SessionTrigger } from '@finalai/agents/o11y';

await o11y.judges.setJudgeRunSettings({
  judgeId,
  runSettings: {
    online: true,
    environments: ['prod'],
    samplingPercent: 100,
    sessionTrigger: { kind: SessionTrigger.Inactivity, inactivityMinutes: 30 },
  },
});

const session = await o11y.traces.getSession({ sessionId: 'ases_…' });
for (const score of session.scores)
  console.log(score.fromTraceSeq, score.toTraceSeq, score.label);
```

Each evaluation covers an explicit range of the session's turns. A session that continues gets new windows; earlier results are never rewritten.

## Backfills

`backfillJudge` runs a judge at its pinned version over the traces in a time range, optionally narrowed by a trace filter: environments, statuses, root span names, operations, models, agents and agent versions, workflows, sessions, labels, cost, duration, span attributes and text. `evaluateAllTraces` does the same for up to 20 judges and any filter. Ask for the estimate first with `dryRun: true`:

```ts
const estimate = await o11y.judges.evaluateAllTraces({
  judgeIds: [judgeId],
  filter: { agentIds: ['adef_…'], from: '2026-11-13T00:00:00Z' },
  dryRun: true,
});
console.log(estimate.targetCount, estimate.estimatedCostUsd);
```

Run it again without `dryRun` to start. A backfill is a batch: follow it with `listEvaluations({ batchId })` and stop it with `cancelEvaluations({ batchId })`. To score specific traces instead, pass their IDs to `evaluateTraces` or `runJudge`; see [backfill past runs](/o11y/quickstart-workflows#backfill-past-runs). Backfills never start actions.

## Limits

Online evaluation and test scoring each have a per-project rate: a burst of 100 and 100 per minute. Evaluations over the rate are recorded as `skipped_rate_limited`, never dropped silently. An agent judge whose budget or spending restriction refuses the spend is recorded as `skipped_budget`.

| Judge type | Deadline per evaluation |
| --- | --- |
| `agent` | 10 minutes |
| `code` | 60 seconds (and 5 seconds of CPU) |
| `deterministic` | 30 seconds |

## Which evaluations start actions

| Trigger | Publishes `o11y.judge.matched` |
| --- | --- |
| Online, at the judge's pinned version | Yes |
| `runJudge`, `evaluateTraces`, `evaluateAllTraces`, `backfillJudge` | No |
| Test runs and rescoring | No |
| External results | No |

An evaluation that fails (`evaluator_error` or `timeout`) publishes `o11y.evaluation.failed`, whatever started it.
