Every Observability operation is one Final MCP tool, 180 in all. Its catalog path is `final.o11y.<group>.<tool>`, for example `final.o11y.traces.search_traces`. Every tool takes `projectId`. The same operation is an HTTP route under `/v1/o11y`, a method on `client.project(id).<group>` in the SDK, and a `final-o11y <group> <tool>` command.

**Scope** is the API key permission the call needs. **Effect** is what it does: `read` changes nothing, `write` creates or changes something, `execute` starts work that runs (and may spend money), and `destructive` deletes or replaces something that can't be recovered. See [scopes and keys](/o11y/reference/scopes).
