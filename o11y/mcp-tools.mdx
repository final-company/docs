Every Observability operation is one tool on the Final MCP gateway, 115 in all. Its catalog path is `final.o11y.<group>.<verb>`: the tool name, without the group's noun when that leaves it unambiguous, so `list_judges` is `final.o11y.judges.list`. Every tool takes `projectId`.

The same operation is the HTTP route `/api/v1/o11y/projects/{projectId}/…` on the agents API, the method `project.o11y.<group>.<method>` in `@finalai/agents/client`, and the command `final-agents o11y <group> <tool-name>` (with `-` for `_`).

**Scope** is the permission the call needs. **Effect** is what it does: `read` changes nothing, `write` creates or changes something, `execute` starts work that runs (and may spend), and `destructive` deletes something. In an agent session, every tool but a `read` asks for approval first. See [scopes and roles](/o11y/reference/scopes).
