Final records your agents' turns and workflow runs as they happen. Observability reads those records in place and represents each as an OpenTelemetry trace, following the [GenAI semantic conventions](https://opentelemetry.io/docs/specs/semconv/gen-ai/). The same spans appear in the console's waterfall, the trace API, judges' evidence, SQL and [trace export](/o11y/trace-export). The constants are in `@finalai/agents/o11y`: `GenAiAttribute`, `OtelAttribute`, `FinalAttribute` and `GenAiOperationName`.

## Trace shapes

### An agent turn

| Span | Name | Kind | Holds |
| --- | --- | --- | --- |
| Root | `invoke_agent` | `internal` | The turn: agent, session, agent version, models, finish reason, token totals, and the turn's input and output messages. |
| Model call | `chat <model>` | `client` | One model request: provider, model, response ID, tokens and cost. |
| Tool call | `execute_tool <tool>` | `internal` | One tool call: its name, ID, type, arguments and result. |

Model and tool calls are children of the root, in start order. Cost sits on the `chat` spans that spent it, so summing spans counts it once; the trace's `costUsd` is that sum.

### A workflow run

| Span | Name | Kind | Holds |
| --- | --- | --- | --- |
| Root | `workflow <workflow name>` | `internal` | The run: workflow, version and run ID, its input and result. |
| Step | `step <step id>` | `internal` | One step, from when it started (or started waiting) to when it finished. A step that failed and then succeeded on a retry is `ok`. |

### Links

A workflow run's root links to the trace of every agent turn its steps started, and each of those turns' roots links back to the run. Both links carry `final.link.relation: subagent`. `getTrace` returns them as `linkedTraces` and `parentTrace`.

### IDs and status

Trace IDs are 32 lowercase hex characters and span IDs 16, as OpenTelemetry requires, and they're stable: the trace API, SQL views, judge citations and exported spans all name the same trace and span the same way.

A span's status is `ok` or `error`; a trace's status is its root's. A failed span carries `error.type`. A turn's root is `error` when the turn ended in error or timed out; a run's root is `error` when the run failed.

### Resource

Every span is recorded under a resource with `service.name` set to `final` and `deployment.environment.name` set to the environment. Agents and workflows running on Final report `prod`.

## GenAI attributes

| Attribute | On | Value |
| --- | --- | --- |
| `gen_ai.operation.name` | Every agent span | `invoke_agent`, `chat` or `execute_tool`. |
| `gen_ai.provider.name` | Root, `chat` | `final` on the root; the model provider on a `chat` span. |
| `gen_ai.conversation.id` | Root | The Final session the turn belongs to. |
| `gen_ai.agent.id` | Root | The agent's ID. |
| `gen_ai.agent.name` | Root | The agent's name. |
| `gen_ai.request.model` | Root, `chat` | The model requested. On the root, set when the turn used one model. |
| `gen_ai.response.id` | `chat` | The provider's response ID. |
| `gen_ai.response.finish_reasons` | Root | Why the turn stopped, such as `end_turn`. |
| `gen_ai.usage.input_tokens` | Root, `chat` | Input tokens. |
| `gen_ai.usage.output_tokens` | Root, `chat` | Output tokens. |
| `gen_ai.tool.name` | `execute_tool` | The tool's name. |
| `gen_ai.tool.call.id` | `execute_tool` | The tool call's ID. |
| `gen_ai.tool.type` | `execute_tool` | The kind of tool. |
| `gen_ai.tool.call.arguments` | `execute_tool` | The call's arguments. Content. |
| `gen_ai.tool.call.result` | `execute_tool` | The call's result. Content. |
| `gen_ai.input.messages` | Root | The turn's input messages, or a run's input as JSON. Content. |
| `gen_ai.output.messages` | Root | The turn's reply messages, or a run's result as JSON. Content. |

Messages follow the conventions' shape: `{ role, parts }`, with `text` parts for text and other parts for images, files and JSON.

**Content** attributes are left out of span lists (`listTraceSpans`) to keep them small; `getSpan` returns every attribute.

## Final attributes

What the conventions don't cover uses `final.*` keys:

| Attribute | On | Value |
| --- | --- | --- |
| `final.agent.hash` | Root of a turn | The content hash (`sha256:…`) of the agent version that ran. Compare versions by it. |
| `final.turn.id` | Root of a turn | The turn's ID. |
| `final.workflow.id` | Workflow spans | The workflow's ID. |
| `final.workflow.version` | Workflow spans | The workflow version that ran. |
| `final.workflow.run_id` | Workflow spans | The run's ID. |
| `final.workflow.step_id` | Step spans | The step's ID, as the workflow names it. |
| `final.usage.cache_read_tokens` | Root, `chat` | Input tokens read from the provider's cache. |
| `final.usage.cache_creation_tokens` | Root, `chat` | Input tokens written to the provider's cache. |
| `final.usage.reasoning_tokens` | Root, `chat` | Reasoning tokens. |
| `final.usage.cost_usd` | `chat` | The call's cost in USD. Left out when unknown, never 0. |
| `final.link.relation` | Span links | How the linked trace relates: `subagent`, `fork` or `continuation`. |

## Other attributes

| Attribute | On | Value |
| --- | --- | --- |
| `error.type` | Failed spans | The class of error, such as `tool_failed`, `model_call_failed` or the step's error message. |
| `deployment.environment.name` | Resource | The environment. |
| `service.name` | Resource | `final`. |

## Search by attribute

`searchTraces` filters on any span attribute with `attributes: [{ key, op, value }]`, where `op` is `eq`, `ne`, `lt`, `lte`, `gt`, `gte`, `contains`, `not_contains`, `exists` or `not_exists`. Deterministic judges match attributes with the `attribute` condition field. See [judges](/o11y/judges#deterministic-judges).
