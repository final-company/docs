## Scopes

Every operation needs one scope. Grant API keys only the scopes they use.

| Scope | Allows |
| --- | --- |
| `o11y:read` | Every read: traces, sessions, results, labels, datasets, test runs, issues, SQL, dashboards, settings and the trace export configuration. |
| `o11y:write` | Creating, changing and deleting: judges, run settings, code judge source, reviews, datasets, test suites, issues, saved views and queries, dashboards, settings and trace export. |
| `o11y:execute` | Starting work that runs and may spend: running judges, evaluations and backfills, test runs, issue detection, and the trace export test. |

Operations with the effect `destructive` (deleting or removing) need `o11y:write`. The [tool reference](/o11y/mcp-tools) lists the scope and effect of every operation.

## Credentials

| Credential | Use it for | Scopes |
| --- | --- | --- |
| API key | Scripts, CI, the `project.o11y` client and the `final-agents o11y` CLI. Create one in **Developer** > **API keys**; see [Get an API key](/api-keys). | The `o11y:*` permissions you choose. |
| Your Final account | The console, and MCP clients that sign in with Final. | Implied by your account's access: reading projects grants `o11y:read`, changing them `o11y:write`, and running agents `o11y:execute`. |
| An app's token | Apps that act in projects that installed them. | The same implied scopes, from the app's grants, or `o11y:*` scopes granted directly. |

Send the credential as `Authorization: Bearer <token>` to `https://agent-session.final.ai/api/v1/o11y`. The SDK and CLI do this for you.

## Roles

The scope is necessary, not sufficient: your project role also has to allow the operation. Organization admins can do everything.

| Role | Can |
| --- | --- |
| Viewer | Every `read` operation. |
| Editor | Every operation but the admin ones below. |
| Admin | Also `update_settings`, `set_trace_export`, `test_trace_export` and `list_audit_events`. |

## Common combinations

| Task | Scopes |
| --- | --- |
| Read traces and results, run SQL | `read` |
| Create judges and turn on online evaluation | `read`, `write` |
| Try a judge with `runJudge`, or backfill | `read`, `execute` |
| `final-agents o11y test run` | `read`, `execute` |
| Publish a judge agent | `agents:write` |
| Set up trace export | `write`, `execute` for the test, and the project admin role |
