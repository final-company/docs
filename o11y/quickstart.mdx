Send your first trace from a Node app and check that it arrived healthy. You need Node 26 or later and a Final project.

<Steps>
  <Step title="Create an ingest key">
    In the [Final dashboard](https://console.final.ai), go to **Observability** > **Settings**, open the **Ingest keys** tab and click **Create key**. The secret is shown once. An ingest key belongs to one project and can only send telemetry; see [scopes and keys](/o11y/reference/scopes).

    ```bash
    export FINAL_API_KEY='paste-your-ingest-key'
    export FINAL_PROJECT_ID='prj_your_project'
    ```

    `npx final-o11y init` writes these variables to `.env` and creates a `final-o11y.ts` that calls `init`.
  </Step>
  <Step title="Install the SDK">
    ```bash
    npm install @finalai/o11y @finalai/o11y-openai openai
    ```

    This example records OpenAI calls with `@finalai/o11y-openai`. Using another model client or framework? Install [its integration package](/o11y/integrations) instead.
  </Step>
  <Step title="Initialize before your agent code">
    Call `init` once, before the code it traces runs. It reads `FINAL_API_KEY`, `FINAL_PROJECT_ID` and `FINAL_API_URL` when you don't pass them.

    ```ts agent.ts
    import { SpanKind, init, observe, setCustomer, setSession, shutdown } from '@finalai/o11y/node';
    import { wrapOpenAI } from '@finalai/o11y-openai';
    import OpenAI from 'openai';

    init({ environment: 'development' });

    const openai = wrapOpenAI(new OpenAI());

    export const answer = observe(
      async (question: string, user: { id: string; conversationId: string }) => {
        setSession(user.conversationId);
        setCustomer(user.id);
        const response = await openai.chat.completions.create({
          model: 'gpt-5.1',
          messages: [{ role: 'user', content: question }],
        });
        return response.choices[0]?.message.content;
      },
      { name: 'answer', kind: SpanKind.Agent },
    );

    console.log(await answer('What is OpenTelemetry?', { id: 'cus_42', conversationId: 'conv_1' }));
    await shutdown(); // exports what is still buffered before the process exits
    ```

    `observe` records the function's arguments as `final.input` and its return value as `final.output`. The wrapped OpenAI client records each model call as an `llm` span with the model, usage, tools offered and output.
  </Step>
  <Step title="Run it and check">
    ```bash
    npx tsx agent.ts
    ```

    `final-o11y doctor` reads the trace back, which an ingest key can't do. Create an [API key](/api-keys) with `o11y:read`, pass it as `FINAL_API_KEY`, and pass the ingest key as `FINAL_INGEST_KEY` so the test span is sent with it:

    ```bash
    FINAL_INGEST_KEY="$FINAL_API_KEY" FINAL_API_KEY='paste-your-api-key' npx final-o11y doctor
    ```

    `doctor` checks your credentials, sends a test span, waits for it to arrive and prints the project's trace health:

    ```text
    ✓ credentials work for prj_your_project (environments: development)
    ✓ sent test trace 4bf92f3577b34da6a3ce929d0e0e4736
    ✓ trace received
    ✓ trace health: healthy
    ```

    A failing check prints the share of traces that fail it and how to fix it.
  </Step>
</Steps>

<Check>
Open **Observability** > **Traces** in your project. The `answer` trace shows an `agent` span with an `llm` span under it.
</Check>

## `init` options

| Option | Default | What it does |
| --- | --- | --- |
| `environment` | Required | Sets `deployment.environment.name`. Judges, monitors and dashboards filter on it. |
| `apiKey` | `FINAL_API_KEY` | An ingest key, or an API key with `o11y:ingest`. |
| `baseUrl` | `FINAL_API_URL`, else `https://api.final.ai` | The API origin. With a [BYOC data plane](/o11y/byoc/overview), still Final's API. |
| `projectId` | `FINAL_PROJECT_ID` | Needed only for `tag({ traceIds })` and `asyncEvaluate`. |
| `serviceName` | `unknown_service` | The `service.name` resource attribute. |
| `resourceAttributes` | | Extra resource attributes on every span. |
| `redact` | | Rewrites or drops any attribute before export. Return `undefined` to drop it. |
| `additionalExporters` | | Also export every span to these. See [dual export](/o11y/dual-export). |
| `exporter` | OTLP/HTTP protobuf to Final | Replaces the exporter, for example with an in-memory exporter in tests. |
| `batch` | `true` | Export in batches, or span by span with `false`. |
| `installAsGlobalProvider` | `false` | Make this the global tracer provider for instrumentations that use the global API. |
| `instrumentations` | | OpenTelemetry instrumentations to register with this provider. |
| `onError` | Logs a warning | Called with export and evaluation errors. |

`init` returns a handle with `forceFlush()` and `shutdown()`; the same functions are exported from `/node`.
