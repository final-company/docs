sidebarTitle: "Judge an agent"

You'll add a judge to a Final agent you already run: a second agent that reads each turn and decides whether it resolved the request. You'll publish the judge, try it on yesterday's turns, and turn on online evaluation. It takes about 10 minutes.

**Before you start**, you need:

- An agent published in your project that has run at least a few turns. The [agent quickstart](/quickstart) builds one.
- Node.js 26 or later and `@finalai/agents` 0.29.0 or later.
- A [Final API key](/api-keys) with `o11y:read`, `o11y:write` and `o11y:execute` (add `agents:write` to publish the judge from the same key), and your project ID.

```bash
export FINAL_API_KEY='paste-your-key-here'
export FINAL_PROJECT_ID='prj_your_project'
```

<Steps>
  <Step title="Write the judge agent">
    An agent judge is an ordinary Final agent. Its instructions are the rubric, and its recommended harness and model are what it judges with. Judging is that agent's model use, billed to the project in Final credits, so the [budgets and spending restrictions](/harnesses/settings#subscriptions-and-keys) that apply to it cap what judging spends.

    ```ts judge.ts
    import { defineAgent } from '@finalai/agents';
    import { FinalHarness } from '@finalai/agents/harnesses';

    export const agent = defineAgent({
      name: 'Support judge',
      description: 'Decides whether a support turn resolved the customer request.',
      instructions: `You judge one turn of a support agent.
    Pass when the reply resolves what the customer asked, using only what its tool calls returned.
    Fail when it leaves the request unresolved, invents a fact, or promises something it cannot do.
    Cite the spans you relied on.`,
      require: {
        harness: {
          permissionMode: 'auto',
          recommended: { harness: FinalHarness.Final, model: 'deepseek-v4.1-flash' },
        },
      },
    });
    ```

    A judge agent needs a recommended harness with a model, and nothing else: Final sends it the evidence in its prompt and asks for its verdict as the turn's structured result. It's started with no compute and no integrations.
  </Step>
  <Step title="Publish it">
    ```bash
    npx final-agents publish ./judge.ts --name support-judge
    ```

    ```text
    published support-judge: sha256:4f1c...
    ```

    The hash identifies this exact version of the rubric. You'll pin the judge to it.
  </Step>
  <Step title="Create the judge">
    ```ts create-judge.ts
    import { createClient } from '@finalai/agents/client';
    import { JudgeResponseKind, JudgeScope, JudgeType } from '@finalai/agents/o11y';

    const client = createClient({ auth: { apiKey: process.env.FINAL_API_KEY! } });
    const { o11y } = client.project({ id: process.env.FINAL_PROJECT_ID! });

    const judge = await o11y.judges.createJudge({
      name: 'Resolved the request',
      definition: {
        type: JudgeType.Agent,
        scope: JudgeScope.Trace,
        // The full hash publish printed.
        agent: { name: 'support-judge', hash: 'sha256:4f1c…' },
        responseKind: JudgeResponseKind.Binary,
      },
      // The agent you're judging, by its published name.
      appliesTo: { agents: [{ name: 'support' }] },
    });
    console.log(judge.judgeId, judge.evaluatorVersion);
    ```

    A binary judge without its own `choices` has the labels `Pass` and `Fail`. Leave out `hash` and the judge follows the name's latest publication instead. `appliesTo` keeps online evaluation to your agent's turns; leave it out to judge every agent and workflow in the project.
  </Step>
  <Step title="Try it on recent turns">
    Run the judge on the agent's turns from the last day. `runJudge` scores up to 100 traces now and publishes no `o11y.judge.matched` events, so no [action](/o11y/actions) reacts to a trial.

    ```ts try-judge.ts
    import { createClient } from '@finalai/agents/client';

    const client = createClient({ auth: { apiKey: process.env.FINAL_API_KEY! } });
    const { o11y } = client.project({ id: process.env.FINAL_PROJECT_ID! });
    const judgeId = 'ojdg_…';

    const { items } = await o11y.traces.searchTraces({
      filter: { agentNames: ['support'], from: new Date(Date.now() - 86_400_000).toISOString() },
      limit: 20,
    });
    const batch = await o11y.judges.runJudge({
      judgeId,
      traceIds: items.map((trace) => trace.traceId),
    });

    // Results arrive as each evaluation finishes.
    const { items: results } = await o11y.judges.listEvaluations({ batchId: batch.batchId });
    for (const result of results)
      console.log(result.target.traceId, result.status, result.value?.label, result.reason);
    ```

    Each result has the label, the judge's reason, citations of the spans it relied on, its cost, and the judging session, which you can open like any other session. Read a few. If the judge is wrong, change the instructions, publish again, and pass the new hash to `runJudge` as `evaluatorVersion` to compare before you pin it with `updateJudge`.
  </Step>
  <Step title="Evaluate new turns online">
    ```ts online.ts
    import { createClient } from '@finalai/agents/client';

    const client = createClient({ auth: { apiKey: process.env.FINAL_API_KEY! } });
    const { o11y } = client.project({ id: process.env.FINAL_PROJECT_ID! });
    const judgeId = 'ojdg_…';

    await o11y.judges.setJudgeRunSettings({
      judgeId,
      runSettings: { online: true, environments: ['prod'], samplingPercent: 25 },
    });
    ```

    From now on, a quarter of your agent's finished turns in `prod` are judged at the pinned hash. What judging spends is the judge agent's own model use.
  </Step>
</Steps>

<Check>
Open **Observability** > **Judges** in the console to see the judge's label rates over time, or filter **Traces** by its `Fail` label.
</Check>
