Check a judge against people, correct it, and bring in feedback from outside Final.

## Review sessions

A review session collects a judge's results that match a filter. Reviewers agree or disagree with each one, and give the correct label and a comment when they disagree.

```ts
import { ReviewVerdict } from '@finalai/o11y/contract';

const session = await project.alignment.createReviewSession({
  name: 'Grounding, week 47',
  judgeId,
  filter: { from: '2026-11-17T00:00:00Z', environments: ['production'] },
});

await project.alignment.submitReview({
  reviewSessionId: session.reviewSessionId,
  evaluationId,
  verdict: ReviewVerdict.Disagree,
  correctedLabelId: groundedLabelId,
  comment: 'The claim is supported by the second search result.',
});
```

`list_reviews` filters by verdict, so you can read only disagreements.

## Alignment summary

`get_alignment_summary` reports, for a judge version or review session:

- agreement between the judge and reviewers;
- precision and recall per label;
- the confusion matrix;
- a warning when a label has too few reviews to trust its numbers.

## Improve the rubric

Ask the [observability agent](/o11y/agent) to improve a judge from its disagreements. It drafts a new version of the rubric; you review, publish and promote it. Results keep the version that produced them, so you can compare the old and revised rubrics on the same traces.

## Golden datasets

`create_golden_dataset` turns reviewed results into a dataset with an `expected_<judge>` column holding the reviewers' labels. Use it as test cases to check future judge versions.

## External feedback

External judges hold results from outside Final's evaluators: thumbs up or down from your users, human labels, or your own evaluators. Submit a result on a trace, span, session or conversation:

```ts
import { EvaluationTargetKind } from '@finalai/o11y/contract';

await project.judges.submitJudgeResult({
  judgeId: thumbs.judgeId,
  target: { kind: EvaluationTargetKind.Trace, traceId },
  value: { passed: false },
  reason: 'User clicked thumbs down',
  metadata: { surface: 'web' },
});
```

| Field | What it holds |
| --- | --- |
| `target` | `kind` (`span`, `trace`, `session` or `conversation`) and the matching IDs. |
| `value` | `label`, `score` or `passed`, matching the judge's output. |
| `reason` | Up to 20,000 characters. |
| `citations` | Up to 50 trace and span references with quotes. |
| `metadata` | Any JSON. |

There is one current result per judge and target. Submitting again replaces it and keeps the history (`list_judge_results({ includeHistory: true })`). External results never trigger judges or actions.

Final's own [outcome signals](/o11y/final-agents-and-workflows#outcome-signals) arrive the same way with source `final_outcome`, kept distinct from results you submit (`customer`).
