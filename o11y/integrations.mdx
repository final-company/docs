---
title: "Integrations"
description: "Record OpenAI, Anthropic, the Vercel AI SDK, agent frameworks, LangChain and MCP servers with one call each."
---

Each integration is its own package. It depends on `@finalai/o11y` and is typed against the library it records, which you install yourself. Call `init` (or `initWorkers`) first; integrations record with the tracer provider it sets up.

Every model call is recorded once. A wrapper inside a call that is already recorded (an AI SDK model call, an OpenInference LLM span, or another wrapper) records nothing, so stacking integrations doesn't double-count usage or cost.

| Library | Package | Integration |
| --- | --- | --- |
| `openai` 7 | `@finalai/o11y-openai` | `wrapOpenAI(client)` |
| `@anthropic-ai/sdk` 1 | `@finalai/o11y-anthropic` | `wrapAnthropic(client)` |
| Vercel AI SDK 7 (`ai`) | `@finalai/o11y-ai-sdk` | `finalTelemetryIntegration()` or `aiSdkTelemetry()` |
| OpenAI Agents SDK 0.22 (`@openai/agents`) | `@finalai/o11y-openai-agents` | `openAIAgentsTracingProcessor()` |
| Claude Agent SDK 0.3 (`@anthropic-ai/claude-agent-sdk`) | `@finalai/o11y-claude-agent-sdk` | `traceClaudeAgentQuery(query)` |
| LangChain.js and LangGraph.js (`@langchain/core` 1) | `@finalai/o11y-langchain` | `instrumentLangChain(module)`, through OpenInference |
| MCP servers (`@modelcontextprotocol/server` 2, `@modelcontextprotocol/sdk` 1.29+) | `@finalai/o11y-mcp` | `instrumentMcpServer(server)` |

## OpenAI

```sh
npm install @finalai/o11y @finalai/o11y-openai openai
```

```ts
import { init } from '@finalai/o11y/node';
import { wrapOpenAI } from '@finalai/o11y-openai';
import OpenAI from 'openai';

init({ environment: 'production', apiKey: process.env.FINAL_API_KEY });
const openai = wrapOpenAI(new OpenAI());
```

`chat.completions.create`, `chat.completions.parse`, `responses.create` and `responses.parse` each become an `llm` span with the model, the messages the model saw, tools offered, tool calls, output and usage (including cached and reasoning tokens). Streams are recorded as they're consumed, and the span ends with the stream, including when you stop reading early. Pass `stream_options: { include_usage: true }` to record usage for streamed chat completions. The wrapper returns a proxy; the original client is unchanged, and wrapping a client twice still records each call once.

Pass `{ recordInput: false }` or `{ recordOutput: false }` to leave prompts or completions out. `chatCompletionResult` and `responsesResult` return what is recorded for a response.

## Anthropic

```sh
npm install @finalai/o11y @finalai/o11y-anthropic @anthropic-ai/sdk
```

```ts
import Anthropic from '@anthropic-ai/sdk';
import { init } from '@finalai/o11y/node';
import { wrapAnthropic } from '@finalai/o11y-anthropic';

init({ environment: 'production', apiKey: process.env.FINAL_API_KEY });
const anthropic = wrapAnthropic(new Anthropic());

const message = await anthropic.messages.create({
  model: 'claude-opus-5-5',
  max_tokens: 16000,
  messages: [{ role: 'user', content: 'Summarize this ticket.' }],
});
```

`messages.create` and `messages.stream`, and their `beta` versions, become `llm` spans with the model, usage including cache reads and writes, tools offered, tool calls and output. Input tokens include cache reads and writes. It takes the same `recordInput` and `recordOutput` options as `wrapOpenAI`. `anthropicMessageResult` returns what is recorded for a message.

## Vercel AI SDK

```sh
npm install @finalai/o11y @finalai/o11y-ai-sdk ai
```

Register the integration for every call, or pass telemetry settings to one call:

```ts
import { init } from '@finalai/o11y/node';
import { aiSdkTelemetry, finalTelemetryIntegration } from '@finalai/o11y-ai-sdk';
import { generateText, registerTelemetry } from 'ai';

init({ environment: 'production', apiKey: process.env.FINAL_API_KEY });

// Every call:
registerTelemetry(finalTelemetryIntegration());
// Or one call:
await generateText({ model, prompt, telemetry: aiSdkTelemetry({ functionId: 'answer' }) });
```

Each generation is an `agent` span, each model call an `llm` span with usage, and each tool execution a `tool` span. Options: `functionId` (recorded as `ai.telemetry.functionId`), `recordInputs` and `recordOutputs` (both default `true`); per-call `recordInputs: false` and `recordOutputs: false` apply as well. A wrapped OpenAI or Anthropic client called inside a model call runs in that call's context, so the call is recorded once.

## OpenAI Agents SDK

```sh
npm install @finalai/o11y @finalai/o11y-openai-agents @openai/agents
```

```ts
import { init } from '@finalai/o11y/node';
import { openAIAgentsTracingProcessor } from '@finalai/o11y-openai-agents';
import { addTraceProcessor } from '@openai/agents';

init({ environment: 'production', apiKey: process.env.FINAL_API_KEY });
addTraceProcessor(openAIAgentsTracingProcessor());
```

Each Agents SDK trace becomes an `agent` span, with its group ID as the session. Agent spans become `agent` spans, function and MCP tool calls `tool` spans, and response and generation spans `llm` spans with model, usage, tool calls and output. Handoffs, guardrails and custom spans keep their data in `openai_agents.span_data`. Use `setTraceProcessors([openAIAgentsTracingProcessor()])` instead to stop sending traces to OpenAI as well. Don't also wrap the OpenAI client the Agents SDK uses: this processor already records its model calls.

## Claude Agent SDK

```sh
npm install @finalai/o11y @finalai/o11y-claude-agent-sdk @anthropic-ai/claude-agent-sdk
```

Wrap the `query()` you iterate:

```ts
import { query } from '@anthropic-ai/claude-agent-sdk';
import { init } from '@finalai/o11y/node';
import { traceClaudeAgentQuery } from '@finalai/o11y-claude-agent-sdk';

init({ environment: 'production', apiKey: process.env.FINAL_API_KEY });

const prompt = 'Find the flaky test in this repository.';
for await (const message of traceClaudeAgentQuery(query({ prompt }), { prompt })) {
  console.log(message.type);
}
```

Messages pass through unchanged. The run is an `agent` span with the session ID, model, cost and turn count; each model turn is an `llm` span with usage, tool calls and output, and each tool use a `tool` span. A subagent's turns nest under the Task tool that started it. Options: `name` (default `claude agent`), `prompt` (recorded as the run's input) and `recordOutput` (default `true`).

## LangChain.js and LangGraph.js

```sh
npm install @finalai/o11y @finalai/o11y-langchain @langchain/core
```

LangChain is traced through OpenInference's LangChain instrumentation, which the package includes. Pass the callback manager module, imported as a namespace, after `init`:

```ts
import { init } from '@finalai/o11y/node';
import { instrumentLangChain } from '@finalai/o11y-langchain';
import * as CallbackManagerModule from '@langchain/core/callbacks/manager';

init({ environment: 'production', apiKey: process.env.FINAL_API_KEY });
instrumentLangChain(CallbackManagerModule);
```

Chains, agents, retrievers and tools become OpenInference spans, and chat models `LLM` spans with model, usage and tool calls. It returns the `LangChainInstrumentation`; pass your own as `instrumentation` to use your own OpenInference trace configuration.

## MCP servers

```sh
npm install @finalai/o11y @finalai/o11y-mcp @modelcontextprotocol/server
```

Instrument your server before registering tools; each tool call becomes a `tool` span that continues the caller's trace context from the request `_meta`:

```ts
import { init } from '@finalai/o11y/node';
import { instrumentMcpServer } from '@finalai/o11y-mcp';
import { McpServer } from '@modelcontextprotocol/server';
import * as z from 'zod';

init({ environment: 'production', apiKey: process.env.FINAL_API_KEY });

const server = instrumentMcpServer(new McpServer({ name: 'docs', version: '1.0.0' }), {
  serverName: 'docs',
});

server.registerTool(
  'search',
  { inputSchema: z.object({ query: z.string() }) },
  async ({ query }) => ({ content: [{ type: 'text', text: `Results for ${query}` }] }),
);
```

It works with `registerTool` on an `McpServer` from `@modelcontextprotocol/server` 2.x or `@modelcontextprotocol/sdk` 1.x, with Zod 4 schemas. Both are optional peer dependencies: install the one your server uses.

### What the calling agent reports

Instrumented tools advertise three optional arguments that the calling agent fills in. They're recorded on the span and removed before your handler runs:

| Argument | Recorded as |
| --- | --- |
| `intent` | `final.mcp.intent`: why the agent called the tool, in one sentence. |
| `llm_model` | `final.mcp.llm_model`: the model the agent runs as. |
| `conversation_id` | `final.session_id`: the conversation ID this server returned earlier. |

The session is your app's own ID when you pass `sessionId`, else the echoed `conversation_id`, else a generated ID handed back to the agent, else the transport session. `final.mcp.session_source` records which (`app`, `echoed`, `generated` or `transport`).

| Option | Default | What it does |
| --- | --- | --- |
| `serverName` | | Recorded as `final.mcp.server_name`. |
| `injectAgentArguments` | `true` | Advertise the three arguments. |
| `arguments` | | Rename an argument (`{ intent: 'reason' }`) or drop one (`{ llmModel: false }`). |
| `sessionId` | | A function of `{ toolName, extra }` that returns your app's session ID for a call. |
| `generateConversationIds` | `true` | Generate a conversation ID when there is none and return it to the agent. |
| `capture` | Off | `{ arguments: true, result: true }` records tool arguments and results. |
| `redact` | | `(value, part) => value` applied to captured arguments and results. |

## Other OpenTelemetry instrumentations

Register any OpenTelemetry or OpenInference instrumentation with the Final tracer provider:

```ts
import { init } from '@finalai/o11y/node';

init({ environment: 'production', instrumentations: [new SomeInstrumentation()] });
```

Instrumentations that use the global tracer provider need `installAsGlobalProvider: true`.
