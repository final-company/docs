The Agent SDK lets you build an agent as a folder of files: instructions in Markdown, tools in TypeScript. Final runs it for you, including the model calls, tool calls, working files, and chat history, and your app talks to it through a typed client.

Here's a complete agent and the code that calls it:

<CodeGroup>


```ts agent/tools/release_checklist.ts
import { defineTool } from '@finalai/agents';
import { z } from 'zod';

export default defineTool({
  description: 'List the checks a release must pass before it ships.',
  inputSchema: z.object({ version: z.string() }),
  execute: ({ version }) => ({
    version,
    checks: ['CI is green on main', 'CHANGELOG.md has an entry', 'Release owner signed off'],
  }),
});
```

```markdown agent/instructions.md wrap
You help maintainers decide whether a release is ready to ship.
Call release_checklist for the version, then list each check as done or missing.
```

```ts ask.ts
import { createClient } from '@finalai/agents/client';

const client = createClient({
  host: 'https://agent-session.final.ai/api',
  auth: { apiKey: process.env.FINAL_API_KEY! },
});

const { response } = await client.sessions.create({
  agent: 'release-assistant',
  message: 'Is 1.2.0 ready to ship?',
});

console.log((await response!.result()).text);
```

</CodeGroup>

## How it works

1. **You write the agent as files.** `agent.ts` picks the model and runtime. Markdown files hold instructions and skills. TypeScript files in `tools/`, `connections/`, `schedules/`, and other folders add capabilities. The folder name decides what each file is.
2. **You publish it.** `npx final-agents publish` uploads the folder and creates a **revision**, an immutable snapshot of the agent. New sessions use the latest revision.
3. **Your app starts sessions.** A **session** is one ongoing thread with the agent. Each message you send starts a **turn**: Final runs the model, calls tools, and streams the output back until the turn ends.

[How agents work](/concepts) explains these ideas in more depth.

You'll need a [Final API key](/api-keys) to publish and run agents. If you want to use Claude Code or another existing AI client with your connected accounts instead of building an agent, use the [MCP gateway](/mcp-gateway/overview).
